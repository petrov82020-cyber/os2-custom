Глава 4: Виджеты — добавление и настройка

✍️ Время чтения: ~25 минут | 🎯 Цель: освоить все основные виджеты Elementor и научиться настраивать их для типовых задач сайта

В предыдущей главе мы разобрались с контейнерами — структурой страницы. Теперь пришло время наполнить её содержимым. Виджеты — это функциональные элементы, из которых состоит любая страница: заголовки, текст, изображения, кнопки, иконки, видео и многое другое. В этой главе мы подробно разберём каждый базовый виджет и научимся решать с их помощью реальные задачи.

💡 Что такое виджет?
Виджет — это готовый элемент дизайна, который вы перетаскиваете на страницу и настраиваете через панель. Каждый виджет имеет три вкладки настроек: Содержимое (что показываем), Стиль (как выглядит) и Дополнительно (поведение и отступы). В бесплатной версии Elementor доступно более 40 виджетов.

4.1 Категории виджетов

Все виджеты в Elementor сгруппированы по категориям. Вот основные из них:

📝 Базовые (Basic) Заголовок, Текст, Изображение, Видео, Кнопка, Разделитель, Интервал, Иконка, Список, Google Карты.
📊 Общие (General) Изображение с текстом, Галерея, Счётчик, Прогресс, Отзыв, Соцсети, Иконка-бокс, Аккордеон, Спойлер, Рейтинг.
📐 Структура (Structure) Контейнер, Внутренняя секция, Колонки. Отвечают за построение макета.
🌐 WordPress Записи, Страницы, Меню, Мета-виджеты. Интеграция с возможностями WordPress.

В этой главе мы разберём базовые виджеты — их достаточно для создания 90% контента на типовом сайте. Остальные категории рассмотрим в следующих главах.

4.2 Как добавить виджет на страницу

Есть три способа добавить виджет. Выберите тот, который удобнее в конкретной ситуации.

Способ 1: Перетаскивание из панели

  1. Откройте панель виджетов. Нажмите на иконку Elementor в левом верхнем углу или кнопку «+» в верхней панели.
  2. Найдите нужный виджет. Используйте поиск или разверните категорию.
  3. Перетащите виджет из панели в нужный контейнер на холсте. Появится синяя линия — индикатор места вставки.
  4. Отпустите кнопку мыши — виджет добавится в контейнер.

Способ 2: Клик по «+» в контейнере

  1. Наведите курсор на контейнер. Внутри появится синяя иконка «+».
  2. Нажмите на неё — откроется панель виджетов.
  3. Кликните по нужному виджету — он автоматически добавится в контейнер.

Способ 3: Горячая клавиша

  1. Выделите контейнер на холсте.
  2. Нажмите Ctrl + E (или Cmd + E на Mac) — откроется поиск виджетов.
  3. Начните вводить название — например, заголовок.
  4. Нажмите Enter — виджет добавится.
💡 Совет: Если виджет добавлен не в тот контейнер, просто перетащите его в нужное место. Elementor покажет синюю линию — индикатор новой позиции.

4.3 Виджет «Заголовок» (Heading)

Заголовок — один из самых важных виджетов. Он структурирует контент, помогает поисковым системам понять иерархию страницы и привлекает внимание посетителей.

Настройки вкладки «Содержимое»

Настройка Что делает
Заголовок (Title) Текст заголовка. Введите сюда нужную фразу.
Ссылка (Link) Можно сделать заголовок кликабельным. Введите URL или выберите страницу.
Размер (Size) Уровень HTML-тега: H1–H6 или P (абзац). Важно: H1 используется только один раз на странице — это главный заголовок. Для подзаголовков — H2, H3 и так далее.
Выравнивание (Alignment) По левому краю, по центру, по правому краю или по ширине.

Настройки вкладки «Стиль»

  • Цвет текста (Text Color): выберите цвет заголовка.
  • Типографика (Typography): шрифт, размер, вес, межстрочный интервал, межбуквенное расстояние.
  • Тень текста (Text Shadow): добавьте тень для эффекта объёма.
  • Обводка текста (Text Stroke): добавьте контур вокруг букв.
  • Эффект при наведении (Hover): измените цвет или добавьте анимацию при наведении курсора.
⚠️ Важно: Не путайте уровень заголовка (H1–H6) и размер шрифта. Уровень важен для SEO и доступности, размер — для визуального оформления. Можно сделать H2 визуально крупнее H1, но для поисковиков иерархия останется правильной.

4.4 Виджет «Текст» (Text Editor)

Текстовый редактор — это полноценный аналог Word для веба. Здесь можно писать абзацы, создавать списки, добавлять ссылки и форматировать текст.

Возможности редактора

  • Жирный, курсив, подчёркивание — стандартное форматирование.
  • Списки: маркированные и нумерованные.
  • Ссылки: вставка гиперссылок на внешние и внутренние страницы.
  • Цитаты и код: блоки для выделения особого контента.
  • Выравнивание: по левому краю, по центру, по правому краю, по ширине.
  • Цвет текста и фона — выделение фрагментов.

Настройки вкладки «Стиль»

  • Цвет текста — основной цвет всего блока.
  • Типографика — шрифт, размер, межстрочный интервал. Можно настроить отдельно для абзацев, ссылок, заголовков H1–H6 внутри текста.
  • Столбцы (Columns) — разбить текст на 1–10 колонок. Работает автоматически: браузер распределит текст по колонкам.
💡 Практический приём: Используйте виджет «Текст» для основного контента страницы. Если нужно вставить большой объём, разбейте его на несколько виджетов «Текст» с подзаголовками (Heading) между ними — так страница будет лучше структурирована.

4.5 Виджет «Изображение» (Image)

Изображения делают сайт живым и наглядным. Виджет «Изображение» добавляет на страницу картинку из медиабиблиотеки WordPress или по внешней ссылке.

Настройки вкладки «Содержимое»

  1. Выберите изображение. Нажмите на иконку изображения в настройках виджета и выберите файл из медиабиблиотеки или загрузите новый.
  2. Заполните альтернативный текст (Alt Text). Это описание изображения для поисковых систем и незрячих пользователей. Обязательное поле для SEO!
  3. Настройте размер. Выберите из доступных размеров (например, Большой, Средний, Миниатюра) или задайте свой.
  4. Добавьте подпись (Caption). Текст под изображением.
  5. Добавьте ссылку (Link). Куда ведёт клик по картинке: страница, файл, произвольная ссылка.

Настройки вкладки «Стиль»

  • Выравнивание (Alignment): по левому краю, по центру, по правому краю.
  • Ширина (Width): в процентах или пикселях. По умолчанию 100%.
  • Максимальная ширина (Max Width): ограничивает изображение по ширине.
  • Высота (Height): фиксированная высота.
  • Прозрачность (Opacity): 0–100%.
  • Фильтры CSS: размытие, яркость, контраст, насыщенность, оттенок.
  • Границы (Border): толщина, цвет, стиль.
  • Скругление углов (Border Radius): от 0 до полного круга.
  • Тень (Box Shadow): тень вокруг изображения.
💡 Оптимизация изображений: Перед загрузкой сжимайте картинки (например, через TinyPNG или Squoosh). Оптимальный размер для веба — до 200 КБ, формат WebP или JPEG. Это критично для скорости загрузки сайта.

4.6 Виджет «Кнопка» (Button)

Кнопка — ключевой элемент для призыва к действию (CTA). Именно на кнопки кликают посетители: «Связаться», «Купить», «Записаться», «Скачать».

Настройки вкладки «Содержимое»

  • Тип кнопки: «Default» (стандартная) или «Info Box» (с иконкой и описанием).
  • Текст: надпись на кнопке. Формулируйте кратко: 2–4 слова.
  • Ссылка: куда ведёт кнопка. Можно добавить nofollow для внешних ссылок.
  • Размер: Tiny, Small, Medium, Large, Extra Large.
  • Выравнивание: по левому краю, по центру, по правому краю, на всю ширину.

Настройки вкладки «Стиль»

  • Обычное состояние: цвет текста, типографика, фон (цвет или градиент), границы, тень, скругление.
  • При наведении (Hover): отдельные настройки для состояния, когда курсор над кнопкой. Здесь можно изменить цвет фона, цвет текста, добавить тень, анимацию.
  • Анимация при наведении: более 20 эффектов — от простого изменения цвета до сложных анимаций.
⚠️ Важно: Всегда настраивайте состояние Hover. Кнопка без реакции на наведение выглядит «мёртвой» и не даёт пользователю понять, что она кликабельна. Достаточно слегка изменить оттенок фона или добавить тень.

4.7 Виджет «Иконка» (Icon)

Иконки — универсальный способ добавить визуальный акцент: обозначить преимущество, контакт, соцсеть или услугу. Elementor предлагает огромную библиотеку иконок.

Как добавить и настроить иконку

  1. Перетащите виджет «Иконка» в контейнер.
  2. Выберите иконку. В настройках «Содержимое» → «Иконка» нажмите на текущую иконку, чтобы открыть библиотеку.
  3. Найдите нужную. Используйте поиск или выберите из категорий (Solid, Regular, Brands).
  4. Настройте ссылку. Если нужно, добавьте URL — иконка станет кликабельной.
  5. Задайте размер. В настройках «Стиль» → «Размер» выберите Small, Medium, Large или задайте свой.
  6. Настройте цвет. «Основной цвет» — обычное состояние, «Цвет при наведении» — при наведении.
  7. Добавьте отступы через Padding, если нужно.
💡 Практический приём: Для блока «Преимущества» создайте три контейнера, в каждом — иконку, заголовок и текст. Иконки сделайте одного размера и цвета — это создаст единый стиль. Например, синие иконки в кружочках.

4.8 Виджет «Список» (Icon List)

Список с иконками — отличный способ перечислить преимущества, особенности товара или этапы работы. Каждый пункт может иметь свою иконку, цвет и ссылку.

Настройка списка

  1. Перетащите виджет «Список» в контейнер.
  2. Добавьте первый пункт. В настройках «Содержимое» введите текст.
  3. Выберите иконку для пункта (клик по иконке рядом с текстом).
  4. Нажмите «Добавить элемент» — появится новый пункт списка.
  5. Повторите для всех пунктов.
  6. Настройте стиль. Выберите размер иконок, расстояние между ними, цвет, типографику.

4.9 Виджет «Разделитель» (Divider)

Разделитель — горизонтальная линия, которая визуально отделяет блоки контента. Это простой, но эффективный инструмент для структурирования страницы.

Настройки разделителя

  • Стиль: сплошная, пунктирная, точечная, двойная линия.
  • Вес (Weight): толщина линии в пикселях.
  • Цвет: цвет линии.
  • Ширина: можно задать в процентах, чтобы линия не была на всю ширину.
  • Выравнивание: по левому краю, по центру, по правому краю.
  • Интервал (Gap): расстояние от линии до соседних элементов.

4.10 Виджет «Интервал» (Spacer)

Интервал добавляет пустое пространство между блоками. Это «воздух», который делает дизайн дышащим и облегчает восприятие контента.

Как использовать интервал

  1. Перетащите виджет «Интервал» между двумя контейнерами.
  2. Задайте высоту. В настройках укажите нужное значение в пикселях (например, 40px) или в vh.
  3. Настройте адаптивность. На мобильных высоту можно уменьшить, чтобы не тратить место на пустоту.
💡 Альтернатива: Вместо виджета «Интервал» можно использовать Margin или Padding у контейнера. Это предпочтительнее, потому что не создаёт лишний HTML-элемент. Используйте «Интервал» только когда нужно быстро добавить пространство без настройки контейнера.

4.11 Виджет «Видео» (Video)

Виджет «Видео» добавляет на страницу ролик с YouTube, Vimeo или загруженный на сайт файл. Видео повышает вовлечённость и хорошо работает на лендингах.

Как добавить видео

  1. Перетащите виджет «Видео» в контейнер.
  2. Выберите источник: YouTube, Vimeo, Dailymotion или самохостинг (HTML5).
  3. Вставьте ссылку на видео.
  4. Настройте параметры: автозапуск, отключение звука, показ похожих видео, скрытие управления.
  5. Добавьте изображение-заглушку (Overlay Image) — превью, которое видно до нажатия Play. Это улучшает скорость загрузки, потому что видео не загружается сразу.
⚠️ Важно для скорости: Встраивание YouTube-видео напрямую замедляет загрузку страницы, потому что загружается плеер YouTube. Используйте изображение-заглушку и ленивую загрузку (Lazy Load) — это стандартные настройки виджета «Видео».

4.12 Виджет «Google Карты» (Google Maps)

Карты нужны на страницах контактов, в блоках с адресом и на лендингах с физическим местоположением.

Как добавить карту

  1. Перетащите виджет «Google Карты» в контейнер.
  2. Введите адрес в поле «Location». Например: «Москва, Красная площадь, 1».
  3. Настройте масштаб (Zoom). От 1 (весь мир) до 20 (отдельный дом).
  4. Задайте высоту карты в пикселях.
  5. Настройте стиль. Можно изменить цветовую схему карты или добавить CSS-фильтр (например, сделать её чёрно-белой).
💡 Совет: Не используйте карту на всю ширину экрана, если она не несёт ключевой информации. Оптимально — карта шириной 50% в паре с контактной информацией рядом.

4.13 Практические примеры: решаем типовые задачи

Задача 1: Секция «О нас» с текстом и изображением

  1. Создайте контейнер (Flexbox, Row).
  2. Добавьте виджет «Изображение» — ширина 40%.
  3. Добавьте второй контейнер — ширина 60%, Direction → Column.
  4. Во второй контейнер добавьте: Заголовок (H2), Текст (2–3 абзаца), Кнопку.
  5. Настройте отступы: Padding 40px у второго контейнера.
  6. Проверьте адаптивность: на мобильном Direction → Column для родительского контейнера.

Задача 2: Блок с тремя преимуществами

  1. Создайте контейнер (Flexbox, Row, Wrap).
  2. Добавьте три вложенных контейнера — ширина 33.33% каждый.
  3. В каждом разместите: Иконку, Заголовок (H3), Текст.
  4. Настройте выравнивание по центру.
  5. Задайте одинаковый Padding (например, 20px) для всех трёх.
  6. Настройте планшет (50%) и телефон (100%).

Задача 3: Кнопка с иконкой

  1. Добавьте виджет «Кнопка».
  2. Введите текст: «Позвонить».
  3. Добавьте иконку. В настройках «Содержимое» → «Иконка» выберите иконку телефона.
  4. Настройте позицию иконки: до или после текста.
  5. Задайте ссылку: tel:+79001234567 — при клике на телефоне откроется звонилка.
  6. Настройте стиль Hover: измените цвет фона при наведении.

Задача 4: Блок FAQ с аккордеоном

  1. Добавьте виджет «Аккордеон» в контейнер.
  2. Нажмите «Добавить элемент» — создайте первый вопрос.
  3. Введите заголовок вопроса (например, «Сколько стоит доставка?»).
  4. Введите содержимое ответа в текстовое поле.
  5. Повторите для всех вопросов.
  6. Настройте стиль: цвет заголовка, иконки, границы.

4.14 Решение частых проблем с виджетами

Проблема Решение
Виджет не перетаскивается Проверьте, что вы тянете за иконку-ручку (шесть точек), а не за текст. Убедитесь, что контейнер не заблокирован.
Изображение растянулось В настройках стиля задайте ширину не 100%, а конкретное значение, или установите Max Width.
Кнопка не кликается Проверьте, что в настройках «Содержимое» → «Ссылка» указан URL. Без ссылки кнопка остаётся декоративной.
Текст выглядит слишком мелко Перейдите в «Стиль» → «Типографика» и увеличьте размер шрифта. Проверьте размер на мобильном отдельно.
Заголовок не помещается в строку Уменьшите размер шрифта или используйте адаптивность: на мобильном задайте меньший размер.
Виджет исчез после сохранения Проверьте навигатор — возможно, он попал в скрытый контейнер. Также проверьте настройки адаптивности: виджет мог быть скрыт для текущего устройства.

4.15 Практическое задание

📝 Задание для самопроверки

Часть 1: Секция «О нас»
1. Создайте контейнер (Row, Align Items → Center).
2. Добавьте изображение (ширина 40%) и заголовок H2.
3. Добавьте текст и кнопку «Узнать больше».
4. Настройте кнопку: цвет фона синий, при наведении — тёмно-синий.

Часть 2: Блок преимуществ
5. Создайте контейнер (Row, Wrap).
6. Добавьте три вложенных контейнера по 33.33%.
7. В каждом: иконка (щит, звезда, сердце), заголовок H3, текст.
8. Выровняйте всё по центру.

Часть 3: Блок FAQ
9. Добавьте аккордеон с тремя вопросами.
10. Настройте: цвет заголовка чёрный, иконка плюс/минус, границы серые.

Часть 4: Контакты
11. Добавьте кнопку «Позвонить» с иконкой телефона и ссылкой tel:+7....
12. Добавьте виджет «Google Карты» с вашим адресом.

4.16 Часто задаваемые вопросы

  • Сколько виджетов можно разместить на одной странице? Технически — неограниченно. Но для производительности рекомендуется не более 50–70 виджетов на страницу. Если нужно больше, разбейте контент на несколько страниц.
  • Можно ли копировать виджеты между страницами? Да. Кликните правой кнопкой → «Копировать», затем перейдите на другую страницу → правый клик → «Вставить».
  • Как сделать виджет глобальным? Правый клик по виджету → «Сохранить как глобальный». Изменения в глобальном виджете автоматически применятся везде, где он используется.
  • Почему кнопка выглядит иначе на мобильном? Проверьте настройки адаптивности для кнопки — возможно, на мобильном заданы другие размеры или отступы.
  • Как вставить видео с другого сайта? Используйте виджет «Видео» → источник «YouTube» или «Vimeo». Для других платформ используйте виджет «HTML» и вставьте код вставки.
