Глава 7: Правка файлов темы и дочерние темы

✍️ Время чтения: ~35 минут | 🎯 Цель: освоить безопасную работу с файлами темы и создать дочернюю тему для сохранения правок

Мы подошли к одному из самых важных навыков курса. До сих пор мы работали с CSS через «Дополнительные стили» — это безопасно, но ограниченно. Для более глубокой кастомизации нужно уметь править файлы темы: добавлять функции, подключать скрипты, изменять шаблоны. Но есть проблема: любые правки в файлах темы исчезнут при её обновлении. Решение — дочерняя тема. В этой главе мы разберём оба аспекта.

💡 Главная проблема, которую решает эта глава:
Вы добавили свою функцию в functions.php темы. Через месяц вышло обновление — тема обновилась, и все ваши правки исчезли. Это происходит потому, что WordPress полностью заменяет папку темы при обновлении. Дочерняя тема решает эту проблему: все ваши изменения хранятся отдельно и не затрагиваются при обновлении родительской темы.

7.1 Какие файлы темы можно править

Не все файлы темы одинаковы. Некоторые предназначены для правки, другие — лучше не трогать. Разберём основные.

⚙️
functions.php «Мозг» темы. Здесь добавляют собственные функции, подключают скрипты и стили, регистрируют меню и виджеты. Основной файл для правки.
🎨
style.css Основной файл стилей темы. Содержит информацию о теме (название, автор, версия) и CSS-правила. Правят осторожно.
🧩
theme.json Конфигурация глобальных стилей для блочных тем. Здесь задаются цвета, шрифты, макет. Используется для тонкой настройки FSE.
📄
Шаблоны (index.php, page.php, single.php) Структура страниц. Правят, чтобы изменить вывод контента. Не рекомендуется — используйте Редактор сайта.
🔧
inc/ или includes/ Дополнительные PHP-файлы темы. Обычно содержат вспомогательные функции. Не рекомендуется править напрямую.
📁
templates/ и parts/ HTML-шаблоны для блочных тем. Правятся через Site Editor, а не через FTP. Прямая правка не рекомендуется.
⚠️ Главное правило:
Никогда не правьте файлы темы напрямую — ни через FTP, ни через редактор WordPress. Любые изменения исчезнут при обновлении темы. Для правок используйте дочернюю тему. Единственное исключение — если вы уверены, что тема больше не будет обновляться (например, кастомная тема под конкретный проект).

7.2 Что такое functions.php и зачем он нужен

functions.php — это файл, который WordPress автоматически загружает при запуске темы. Он работает как «плагин темы»: здесь добавляют функции, которые изменяют поведение WordPress.

Что можно делать через functions.php

  • Подключать стили и скрипты: свои CSS и JS-файлы.
  • Регистрировать меню: создавать места для навигации.
  • Регистрировать виджеты: создавать области для виджетов.
  • Добавлять поддержку функций: миниатюры, форматы записей, логотип.
  • Изменять поведение WordPress: убирать лишние скрипты, менять админку, добавлять счётчики аналитики.
  • Создавать шорткоды: собственные шорткоды для вставки контента.
  • Добавлять пользовательские функции: любые PHP-функции для сайта.

Пример простой функции

Вот типичный пример: функция, которая добавляет собственный CSS-файл к теме.

<?php
// Подключаем собственный CSS-файл
function my_theme_styles() {
    wp_enqueue_style(
        'my-custom-styles',
        get_stylesheet_directory_uri() . '/css/custom.css',
        array(),
        '1.0.0'
    );
}
add_action('wp_enqueue_scripts', 'my_theme_styles');

Эта функция подключает файл custom.css из папки css/ вашей темы. WordPress сам вставит его в <head> сайта.

💡 Синтаксис PHP:
  • PHP-код начинается с <?php и заканчивается ?> (закрывающий тег можно не ставить в конце файла).
  • Функции объявляются через function имя() { ... }.
  • Переменные начинаются с $: $variable.
  • Строки в кавычках: 'текст' или "текст".
  • Массивы: array('значение1', 'значение2').
  • Точка с запятой обязательна в конце каждой строки.

7.3 Создание дочерней темы — пошаговая инструкция

Дочерняя тема (Child Theme) — это тема, которая наследует все функции родительской темы, но позволяет безопасно добавлять свои правки. При обновлении родительской темы ваши изменения сохраняются.

Как работает дочерняя тема

❌ Правка родительской темы

  • Изменения в файлах темы
  • При обновлении темы — всё исчезает
  • Нужно каждый раз восстанавливать правки
  • Нет разделения между оригиналом и вашими изменениями

✅ Дочерняя тема

  • Изменения в отдельной папке
  • При обновлении родительской темы — всё сохраняется
  • Один раз настроили — работает всегда
  • Чёткое разделение: родительская тема + ваши правки

Что нужно для создания дочерней темы

Дочерняя тема состоит минимум из двух файлов:

📁 my-child-theme/ ← папка дочерней темы │ ├── 📄 style.css ← обязательный файл с информацией о теме └── 📄 functions.php ← файл для ваших функций

Пошаговое создание дочерней темы

Шаг 1: Узнайте имя папки родительской темы

  1. Откройте «Внешний вид → Темы».
  2. Посмотрите, какая тема активна. Например, Twenty Twenty-Five.
  3. Определите имя папки. Обычно это twentytwentyfive (без пробелов и дефисов). Проверить можно через FTP: папка /wp-content/themes/twentytwentyfive/.

Шаг 2: Создайте папку дочерней темы

  1. Подключитесь к сайту по FTP.
  2. Перейдите в /wp-content/themes/.
  3. Создайте новую папку. Назовите её, например, twentytwentyfive-child (имя родительской темы + -child).

Шаг 3: Создайте файл style.css

  1. Откройте папку дочерней темы.
  2. Создайте файл style.css.
  3. Откройте его в редакторе кода и вставьте:
/*
Theme Name: Twenty Twenty-Five Child
Theme URI: https://ваш_сайт.ru/
Description: Дочерняя тема для Twenty Twenty-Five
Author: Ваше имя
Author URI: https://ваш_сайт.ru/
Template: twentytwentyfive
Version: 1.0.0
License: GNU General Public License v2 or later
License URI: http://www.gnu.org/licenses/gpl-2.0.html
Text Domain: twentytwentyfive-child
*/

/* Здесь ваши собственные CSS-правила */
⚠️ Критически важно: Строка Template: twentytwentyfive должна содержать точное имя папки родительской темы (без пробелов и заглавных букв). Если имя указано неверно, дочерняя тема не активируется.

Шаг 4: Создайте файл functions.php

  1. В той же папке создайте файл functions.php.
  2. Вставьте следующий код:
<?php
/**
 * Функции дочерней темы Twenty Twenty-Five Child
 */

// Подключаем стили родительской темы
function twentytwentyfive_child_enqueue_styles() {
    wp_enqueue_style(
        'parent-style',
        get_template_directory_uri() . '/style.css'
    );
    wp_enqueue_style(
        'child-style',
        get_stylesheet_directory_uri() . '/style.css',
        array('parent-style'),
        '1.0.0'
    );
}
add_action('wp_enqueue_scripts', 'twentytwentyfive_child_enqueue_styles');

Шаг 5: Активируйте дочернюю тему

  1. Вернитесь в админку WordPress.
  2. Перейдите в «Внешний вид → Темы».
  3. Найдите дочернюю тему. Она должна появиться в списке.
  4. Нажмите «Активировать».
  5. Проверьте сайт. Он должен выглядеть так же, как с родительской темой.
✅ Готово! Дочерняя тема создана и активирована. Теперь все правки в functions.php и style.css дочерней темы сохранятся при обновлении родительской темы.

7.4 Добавление собственных функций в дочернюю тему

Теперь, когда дочерняя тема создана, вы можете безопасно добавлять в неё свои функции. Разберём несколько практических примеров.

Пример 1: Добавление счётчика Яндекс.Метрики

Пример 2: Собственный шорткод

Шорткод — это короткий код, который вы вставляете в контент, и он превращается в HTML. Например, [my_button] может выводить стилизованную кнопку.

// Создаём шорткод [my_button]
function my_button_shortcode($atts) {
    $atts = shortcode_atts(array(
        'text' => 'Нажми меня',
        'url'  => '#',
        'color' => '#0969da'
    ), $atts);

    return '<a href="' . esc_url($atts['url']) . '" class="my-shortcode-button" style="background-color:' . esc_attr($atts['color']) . '">'
        . esc_html($atts['text'])
        . '</a>';
}
add_shortcode('my_button', 'my_button_shortcode');

Использование в контенте:

[my_button text="Купить" url="/shop" color="#f97316"]

Пример 3: Отключение лишних функций WordPress

// Отключаем эмодзи (ускоряет загрузку)
function disable_emojis() {
    remove_action('wp_head', 'print_emoji_detection_script', 7);
    remove_action('wp_print_styles', 'print_emoji_styles');
}
add_action('init', 'disable_emojis');

// Убираем версию WordPress из кода (безопасность)
remove_action('wp_head', 'wp_generator');

// Отключаем XML-RPC (защита от брутфорса)
add_filter('xmlrpc_enabled', '__return_false');
💡 Как добавлять код в functions.php:
  • Всегда вставляйте код в конец файла, перед закрывающим тегом ?> (если он есть).
  • Не удаляйте существующий код — только добавляйте.
  • Каждую функцию предваряйте комментарием — что она делает.
  • После добавления кода проверьте сайт: если «белый экран» — восстановите файл.

7.5 Добавление собственных стилей в дочернюю тему

Помимо «Дополнительных CSS», вы можете добавлять стили в style.css дочерней темы. Это удобно для больших проектов.

Как это работает

В functions.php дочерней темы мы подключаем два файла стилей: родительский и дочерний. Браузер загружает оба — и правила дочернего файла «перебивают» правила родительского (если у них одинаковая специфичность).

Пример: переопределение стилей

/* В файле style.css дочерней темы */

/* Изменяем цвет всех кнопок */
.wp-block-button__link {
    background-color: #f97316 !important;
    border-radius: 30px;
    padding: 15px 40px;
}

/* Меняем шрифт заголовков */
h1, h2, h3 {
    font-family: 'Montserrat', sans-serif;
    font-weight: 800;
}

/* Стилизуем определённый блок на главной */
.home .hero-section {
    background: linear-gradient(135deg, #0969da, #f97316);
    padding: 100px 20px;
}

Подключение дополнительных CSS-файлов

Если CSS-кода много, его удобно разбить на файлы. Создайте папку css/ в дочерней теме и подключайте файлы через functions.php.

function my_child_enqueue_custom_styles() {
    // Основной файл дочерней темы
    wp_enqueue_style(
        'child-main',
        get_stylesheet_directory_uri() . '/css/main.css',
        array('parent-style'),
        '1.0.0'
    );

    // Стили для отдельных страниц
    if (is_front_page()) {
        wp_enqueue_style(
            'home-styles',
            get_stylesheet_directory_uri() . '/css/home.css',
            array('child-main'),
            '1.0.0'
        );
    }
}
add_action('wp_enqueue_scripts', 'my_child_enqueue_custom_styles');

7.6 Практический пример: создаём дочернюю тему с нуля

Давайте закрепим теорию практикой. Пройдём весь путь создания дочерней темы.

Задача

  • Активная тема: Twenty Twenty-Five (twentytwentyfive).
  • Создать дочернюю тему twentytwentyfive-child.
  • Добавить кастомный стиль для кнопок.
  • Добавить функцию, которая убирает эмодзи.

Пошаговое решение

  1. Подключитесь к сайту по FTP.
  2. Перейдите в папку /wp-content/themes/.
  3. Создайте папку twentytwentyfive-child.
  4. Создайте файл style.css с заголовком:
/*
Theme Name: Twenty Twenty-Five Child
Template: twentytwentyfive
Version: 1.0.0
*/

/* Кастомные стили для кнопок */
.wp-block-button__link {
    background-color: #f97316 !important;
    border-radius: 30px;
    padding: 15px 35px;
    font-weight: 700;
    transition: all 0.3s ease;
}

.wp-block-button__link:hover {
    background-color: #ea580c !important;
    transform: translateY(-3px);
    box-shadow: 0 6px 20px rgba(249,115,22,0.4);
}
  1. Создайте файл functions.php:
<?php
// Подключаем стили родительской и дочерней темы
function child_enqueue_styles() {
    wp_enqueue_style(
        'parent-style',
        get_template_directory_uri() . '/style.css'
    );
    wp_enqueue_style(
        'child-style',
        get_stylesheet_directory_uri() . '/style.css',
        array('parent-style'),
        '1.0.0'
    );
}
add_action('wp_enqueue_scripts', 'child_enqueue_styles');

// Отключаем эмодзи
function disable_emojis() {
    remove_action('wp_head', 'print_emoji_detection_script', 7);
    remove_action('wp_print_styles', 'print_emoji_styles');
}
add_action('init', 'disable_emojis');
  1. Сохраните файлы.
  2. Вернитесь в админку WordPress.
  3. Перейдите в «Внешний вид → Темы».
  4. Активируйте дочернюю тему.
  5. Проверьте сайт. Кнопки стали оранжевыми, эмодзи отключены.
✅ Результат: Дочерняя тема создана и работает. Теперь при обновлении Twenty Twenty-Five все ваши правки сохранятся.

7.7 Что делать, если сайт «упал» после правки функций

Ошибка в functions.php — самая частая причина «белого экрана». Разберём, что делать.

Диагностика

  1. Не паникуйте. Ошибка в одной строке — не потеря всего сайта.
  2. Подключитесь к сайту по FTP.
  3. Перейдите в папку активной темы (дочерней).
  4. Скачайте файл functions.php на компьютер.
  5. Откройте в редакторе кода (VS Code).
  6. Проверьте: парность фигурных скобок { }, точки с запятой, закрывающие теги.

Быстрое решение

  1. Через FTP переименуйте папку активной темы: my-child-theme → my-child-theme_off.
  2. WordPress автоматически активирует родительскую тему. Сайт заработает.
  3. Верните имя папки обратно: my-child-theme_off → my-child-theme.
  4. Исправьте ошибку в functions.php локально.
  5. Загрузите исправленный файл на сервер.
  6. Активируйте дочернюю тему заново.
⚠️ Важное правило:
Перед правкой functions.php всегда скачивайте его копию на компьютер. Если что-то пойдёт не так — просто вернёте файл через FTP.

7.8 Решение типичных проблем

Проблема Причина Решение
Дочерняя тема не появляется в списке Неверный Template в style.css Проверьте точное имя папки родительской темы
Стили дочерней темы не применяются Не подключены в functions.php Добавьте wp_enqueue_style в functions.php дочерней темы
Белый экран после правки functions.php Синтаксическая ошибка Восстановите файл из бэкапа через FTP
Дочерняя тема наследует не все функции Некоторые функции родительской темы вызываются через файлы, а не через actions Скопируйте нужные файлы из родительской темы в дочернюю
Изменения не видны на сайте Кэш браузера или сайта Очистите кэш (Ctrl+F5)
Ошибка «The package could not be installed» Нет прав на запись в папку Установите права 755 на папку themes
После активации дочерней темы пропали настройки Настройки темы сохранены для родительской темы Это нормально — дочерняя тема использует настройки родительской
Не работает wp_enqueue_style Опечатка в имени функции или файла Проверьте путь к файлу и правильность имени

7.10 Часто задаваемые вопросы

  • Обязательно ли создавать дочернюю тему? Если вы собираетесь править файлы темы (functions.php, style.css) — да, обязательно. Если используете только «Дополнительные CSS» — можно обойтись без неё.
  • Что будет, если удалить дочернюю тему? Сайт вернётся к родительской теме. Все правки в дочерней теме исчезнут вместе с ней.
  • Можно ли использовать дочернюю тему с классической темой? Да, принцип тот же. Разница только в структуре файлов.
  • Нужно ли копировать все файлы родительской темы в дочернюю? Нет, только те, которые вы хотите изменить. Остальные наследуются автоматически.
  • Как узнать, какие функции есть в functions.php родительской темы? Откройте файл через FTP или редактор. Прочитайте код, найдите функции и их назначение.
  • Что делать, если я не знаю PHP? Начните с готовых примеров из этой главы. Копируйте код, меняйте значения. Со временем вы освоите базовый синтаксис.
  • Можно ли добавить в дочернюю тему шаблоны страниц? Да, создайте файл с именем, соответствующим шаблону (например, page-contacts.php), и WordPress будет использовать его для страницы с соответствующим slug.
  • Как проверить, что дочерняя тема работает? Активируйте её и проверьте, что сайт отображается корректно. Посмотрите в исходном коде страницы, что подключается style.css дочерней темы.
  • Что делать, если после активации дочерней темы пропали стили? Проверьте, что в functions.php подключены оба файла: родительский style.css и дочерний.
