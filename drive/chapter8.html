Глава 8: Пакетная загрузка файлов — FTP, WP-CLI, Google Диск, плагины

✍️ Время чтения: ~35 минут | 🎯 Цель: освоить все способы массовой загрузки файлов в WordPress и научиться выбирать подходящий метод для каждой задачи

Загрузить одну картинку через медиабиблиотеку — дело пяти секунд. Загрузить пятьсот картинок тем же способом — это несколько часов монотонной работы. В этой главе мы разберём пять способов пакетной загрузки файлов в WordPress: от простых (через FTP и плагины) до продвинутых (WP-CLI и скрипты). Вы научитесь выбирать подходящий метод для каждой задачи и экономить часы работы.

💡 Почему это важно:
Стандартная медиабиблиотека WordPress имеет лимит на размер файла (обычно 2–128 МБ в зависимости от хостинга) и не умеет загружать папки. Если вам нужно добавить 500 фотографий товаров, 200 изображений для блога или 50 видео — ручная загрузка превращается в пытку. Пакетные методы решают эту проблему.

8.2 Способ 1: FTP + плагин импорта (универсальный)

Этот способ работает на любом хостинге и не имеет ограничений на размер файлов. Вы загружаете файлы по FTP прямо в папку uploads, а затем регистрируете их в медиатеке через плагин.

Плагин Media Sync — пошаговая инструкция

Media Sync — простой и надёжный плагин для регистрации файлов, загруженных по FTP. Он сканирует папку uploads и показывает, какие файлы уже есть в медиатеке, а какие — нет.

  1. Установите плагин Media Sync: «Плагины → Добавить новый → Media Sync».
  2. Активируйте плагин.
  3. Подключитесь к сайту по FTP через FileZilla.
  4. Перейдите в папку /wp-content/uploads/.
  5. Создайте папку для новой партии файлов, например 2026/10/batch-1/.
  6. Загрузите все файлы в эту папку через FTP (перетащите из левой панели в правую).
  7. Вернитесь в админку WordPress.
  8. Перейдите в «Медиафайлы → Media Sync».
  9. Нажмите «Scan» (Сканировать). Плагин покажет все файлы в папке uploads, которых нет в медиатеке.
  10. Выберите файлы для импорта (или нажмите «Select All»).
  11. Нажмите «Import Selected» (Импортировать выбранные).
  12. Дождитесь завершения. Файлы появятся в медиатеке.
💡 Преимущества Media Sync:
  • Показывает, какие файлы уже импортированы (не создаёт дубликатов).
  • Пропускает миниатюры и сгенерированные WordPress файлы.
  • Работает с большими объёмами.
  • Бесплатный и активно обновляется.

Плагин Add From Server Reloaded — для больших файлов

Add From Server Reloaded — более мощный плагин. Он позволяет загружать файлы любого размера (видео 4K, RAW-фото, большие PDF) без изменения настроек PHP.

  1. Установите и активируйте плагин.
  2. Загрузите файлы по FTP в любую папку на сервере.
  3. В админке перейдите в «Медиафайлы → Add From Server».
  4. Укажите корневую папку для сканирования.
  5. Выберите файлы или папки для импорта.
  6. Нажмите «Import». Плагин автоматически зарегистрирует файлы в медиатеке.
⚠️ Важно: Add From Server Reloaded имеет защиту от опасных файлов (PHP, EXE) и защиту от directory traversal. Тем не менее, загружайте только те файлы, которые действительно являются медиафайлами (изображения, видео, PDF).

8.3 Способ 2: WP-CLI — самый быстрый и мощный

WP-CLI — это командная строка WordPress. Через неё можно загрузить сотни файлов одной командой. Это самый эффективный способ для больших объёмов.

Что такое WP-CLI

WP-CLI — это PHP-скрипт, который позволяет управлять WordPress из терминала. Он работает через SSH-подключение к серверу. Команда wp media import импортирует файлы в медиатеку.

Установка WP-CLI

WP-CLI обычно предустановлен на многих хостингах. Проверить просто:

$ wp --info OS: Linux ... Shell: /bin/bash PHP binary: /usr/bin/php PHP version: 8.1.2 ...

Если WP-CLI не установлен, его можно установить вручную:

$ curl -O https://raw.githubusercontent.com/wp-cli/builds/gh-pages/phar/wp-cli.phar $ chmod +x wp-cli.phar $ sudo mv wp-cli.phar /usr/local/bin/wp
💡 Для Windows: WP-CLI можно использовать через Git Bash или WSL (Windows Subsystem for Linux). Также есть возможность установить через Composer.

Базовые команды для загрузки файлов

Загрузка одного файла

$ wp media import /path/to/image.jpg --title="Моё изображение" --alt="Описание"

Загрузка всех JPG из папки

$ wp media import /path/to/images/*.jpg --title="Bulk Upload"

Эта команда загрузит все JPG-файлы из указанной папки в медиатеку и присвоит им заголовок «Bulk Upload».

Загрузка с привязкой к записи

$ wp media import /path/to/image.jpg --post_id=123 --featured_image

Файл будет загружен и назначен как избранное изображение для записи с ID 123.

Загрузка по URL

$ wp media import https://example.com/image.jpg --title="Remote Image"

Загрузка из CSV с метаданными

$ while IFS=',' read -r filepath title alt caption; do $ wp media import "$filepath" --title="$title" --alt="$alt" --caption="$caption" $ done < images.csv

Этот скрипт читает CSV-файл с путями и метаданными и загружает каждый файл с указанными заголовком, alt-текстом и подписью.

Восстановление миниатюр после импорта

Если вы загружали файлы через FTP и зарегистрировали их в медиатеке, WordPress может не создать миниатюры. Для их генерации используйте команду:

$ wp media regenerate --yes Found 3 images to regenerate. 1/3 Regenerated thumbnails for "Sydney Harbor Bridge" (ID 760). 2/3 Regenerated thumbnails for "Boardwalk" (ID 757). 3/3 Regenerated thumbnails for "Sunburst Over River" (ID 756). Success: Regenerated 3 of 3 images.

Команда wp media regenerate пересоздаёт все размеры изображений на основе настроек темы.

⚠️ Важно: Перед использованием WP-CLI убедитесь, что вы находитесь в директории WordPress. Используйте флаг --path=/path/to/wordpress, если команда запускается из другой папки.

8.4 Способ 3: Импорт из Google Диска

Если ваши изображения хранятся в Google Диске, их можно импортировать прямо в медиатеку WordPress без скачивания на компьютер.

Плагин Michael Cloud Image Auto Importer

Этот плагин подключается к Google Диску и импортирует изображения массово. Он поддерживает два метода аутентификации: облачный (через Cloudflare Worker) и традиционный (через Google API).

Ключевые возможности

  • Массовый импорт папок: выбрать целую папку и импортировать все изображения сразу.
  • Обнаружение дубликатов: MD5-хеширование пропускает уже импортированные файлы.
  • Автоматический alt-текст: генерируется из имени файла (например, cat.jpg → «Cat»).
  • Сжатие изображений: опциональное сжатие JPEG/PNG/WebP с контролем качества.
  • Прогресс в реальном времени: полоса прогресса и статистика.

Пошаговая инструкция (метод Cloudflare Worker)

  1. Установите плагин: «Плагины → Добавить новый → Michael Cloud Image Auto Importer».
  2. Активируйте.
  3. Перейдите в настройки плагина.
  4. Нажмите «Connect Google Drive».
  5. Авторизуйте свой аккаунт Google. Плагин использует Cloudflare Worker — API-ключи не нужны!
  6. Вставьте ссылку на папку Google Диска.
  7. Нажмите «Start Import».
  8. Дождитесь завершения. Изображения появятся в медиатеке.

Плагин KFX Media Importer for Google Drive

Альтернативный плагин с похожим функционалом. Использует Google Picker и требует собственные Google API-credentials.

8.5 Способ 4: ZIP-архив + плагин

Если у вас уже есть все файлы на компьютере, самый простой способ — упаковать их в ZIP-архив и загрузить через специальный плагин.

Плагин Nifa Bulk Media Uploader

Nifa Bulk Media Uploader позволяет загружать ZIP-архивы с изображениями и видео. Плагин автоматически распаковывает архив и добавляет все файлы в медиатеку.

Возможности

  • Массовая загрузка: все файлы из ZIP-архива.
  • Drag & Drop интерфейс: удобная загрузка.
  • Отслеживание прогресса: в реальном времени.
  • Настройки: максимальный размер файла, разрешённые типы, пакетная обработка.

Пошаговая инструкция

  1. Упакуйте все файлы в ZIP-архив на компьютере.
  2. Установите плагин Nifa Bulk Media Uploader.
  3. Активируйте.
  4. Перейдите в «Bulk Media Uploader» в админ-меню.
  5. Перетащите ZIP-файл в зону загрузки или нажмите для выбора.
  6. Нажмите «Upload and Process».
  7. Дождитесь завершения. Все файлы из архива появятся в медиатеке.
💡 Альтернатива: Плагин MediaNest Upload Manager — ещё один вариант для пакетной загрузки. Работает аналогично.

8.6 Способ 5: Плагин External Files in Media Library

External Files in Media Library — мощный плагин для подключения внешних источников файлов. Он поддерживает AWS S3, Dropbox, Google Drive, Google Cloud Storage, FTP, локальный хостинг и другие источники.

Ключевые возможности

  • Подключение внешних источников: FTP, SFTP, Google Drive, Dropbox, S3.
  • Массовый импорт: импорт целых директорий через FTP/SFTP.
  • Автоматическая синхронизация:定期 обновление внешних папок.
  • Поддержка WP-CLI: для больших директорий.
  • REST API: управление через API.

Поддерживаемые протоколы

Плагин поддерживает следующие TCP-протоколы: HTTP, HTTPS, FTP, FTPS, SFTP, SSH, FILE.

8.7 Практический пример: загрузка 500 фотографий товаров

Ситуация: Интернет-магазин получил новую партию из 500 товаров. Каждый товар — одна фотография. Нужно загрузить все фото в медиатеку.

Решение через WP-CLI (рекомендуется)

  1. Подготовьте папку с фотографиями на компьютере.
  2. Загрузите папку на сервер по SFTP в директорию /home/user/photos/.
  3. Подключитесь к серверу по SSH.
  4. Перейдите в директорию WordPress: cd /var/www/html.
  5. Выполните команду импорта:
$ wp media import /home/user/photos/*.jpg --title="Товар" --alt="Фото товара" Success: Imported 500 of 500 items.

Все 500 фотографий загружены за одну команду. Время выполнения — 1–2 минуты.

Решение через FTP + Media Sync (если нет SSH)

  1. Подключитесь к сайту по FTP.
  2. Создайте папку /wp-content/uploads/2026/10/products/.
  3. Загрузите все 500 фото в эту папку (перетаскиванием).
  4. В админке перейдите в «Медиафайлы → Media Sync».
  5. Нажмите «Scan». Плагин найдёт все 500 файлов.
  6. Нажмите «Select All» → «Import Selected».
  7. Дождитесь завершения. Все файлы зарегистрированы.
✅ Результат: 500 фотографий загружены за 10–15 минут вместо 4–5 часов ручной работы.

8.8 Практический пример: массовое обновление alt-текста через WP-CLI

Ситуация: У вас 300 изображений в медиатеке, и всем нужно добавить alt-текст для SEO.

Решение

  1. Подключитесь к серверу по SSH.
  2. Создайте CSV-файл с ID и alt-текстом:
ID,alt
760,Сиднейский мост
757,Набережная
756,Закат над рекой
  1. Выполните команду для обновления каждого изображения:
$ while IFS=',' read -r id alt; do $ wp post meta update "$id" _wp_attachment_image_alt "$alt" $ done < alt-texts.csv

Все alt-тексты обновлены одной командой.

8.9 Решение типичных проблем

Проблема Причина Решение
Файлы загружены по FTP, но не видны в медиатеке Они не зарегистрированы в базе данных Используйте Media Sync или Add From Server для регистрации
WP-CLI не найден Не установлен или не в PATH Установите WP-CLI через curl или обратитесь в поддержку хостинга
Ошибка «Image resize failed» Недостаточно памяти PHP Увеличьте memory_limit в php.ini или wp-config.php
ZIP-архив не загружается Превышен лимит загрузки хостинга Увеличьте upload_max_filesize или используйте FTP
Google Drive не подключается Проблемы с аутентификацией Используйте метод Cloudflare Worker (без API-ключей) или проверьте Google API credentials
Дубликаты изображений Файлы импортированы дважды Используйте плагины с обнаружением дубликатов (Michael Cloud, Add From Server)
Миниатюры не созданы WordPress не обработал изображения Выполните wp media regenerate --yes
Скрипт WP-CLI «зависает» на большом количестве файлов Таймаут выполнения Разбейте импорт на партии по 100 файлов

8.11 Часто задаваемые вопросы

  • Какой способ самый быстрый? WP-CLI. Одна команда загружает сотни файлов за секунды. Для 1000+ файлов это единственный разумный вариант.
  • Что делать, если хостинг не поддерживает SSH? Используйте FTP + Media Sync или ZIP-архив через плагин. Эти способы работают на любом хостинге.
  • Можно ли загружать файлы через Google Диск без API-ключей? Да, плагин Michael Cloud Image Auto Importer использует Cloudflare Worker — API-ключи не нужны.
  • Почему файлы по FTP не видны в медиатеке? Потому что WordPress не знает о них. Нужно зарегистрировать их через плагин (Media Sync, Add From Server).
  • Как избежать дубликатов при импорте? Используйте плагины с обнаружением дубликатов: Michael Cloud, Add From Server Reloaded, Media Sync.
  • Что делать, если миниатюры не создались? Выполните wp media regenerate --yes или используйте плагин Regenerate Thumbnails.
  • Можно ли загружать видео через WP-CLI? Да, wp media import работает с любыми типами файлов: изображения, видео, PDF, аудио.
  • Сколько файлов можно загрузить за один раз? Через WP-CLI — неограниченно. Через ZIP — зависит от лимита памяти и размера архива. Через FTP — неограниченно, но медленнее.
  • Что делать, если скрипт WP-CLI прерывается на середине? Разбейте импорт на партии по 50–100 файлов. Например: wp media import /path/batch1/*.jpg.
