Глава 4: Редактор кода — инструменты и правила безопасности

✍️ Время чтения: ~28 минут | 🎯 Цель: выбрать и настроить редактор кода, освоить безопасную работу с файлами и научиться редактировать код без риска для сайта

В предыдущих главах мы научились находить файлы и подключаться к ним по FTP. Но правка кода через встроенный редактор хостинга или FileZilla — это как ремонт часов молотком: возможно, но неудобно и опасно. Для серьёзной работы с кодом нужен правильный редактор. В этой главе мы выберем инструмент, настроим его под работу с WordPress и освоим правила безопасного редактирования.

💡 Почему важен редактор:
Правильный редактор кода:
  • Подсвечивает синтаксис — вы сразу видите ошибки и структуру.
  • Автодополняет код — меньше опечаток, быстрее работа.
  • Находит парные скобки — не потеряете закрывающую скобку в большом файле.
  • Показывает отступы — код остаётся читаемым.
  • Интегрируется с FTP — можно править файлы прямо на сервере.
Блокнот этого не умеет. А одна опечатка в PHP-файле может обрушить весь сайт.

4.2 Установка и настройка VS Code

Установка VS Code занимает 5 минут. Давайте пройдём этот путь вместе.

Шаг 1: Скачивание и установка

  1. Откройте сайт code.visualstudio.com.
  2. Нажмите «Download» — сайт определит вашу ОС автоматически.
  3. Скачайте установщик.
  4. Запустите установщик. Примите лицензию.
  5. Отметьте галочки:
    • «Добавить в PATH» — важно для работы из терминала.
    • «Добавить в контекстное меню проводника» — удобно для быстрого открытия файлов.
    • «Зарегистрировать как редактор для поддерживаемых типов файлов».
  6. Нажмите «Установить».
  7. Запустите VS Code.

Шаг 2: Установка полезных расширений

Расширения — это «плагины» для VS Code. Они добавляют функции. Вот минимальный набор для работы с WordPress.

  1. Откройте панель расширений: иконка квадратов в левой панели или Ctrl+Shift+X.
  2. Установите эти расширения:
    • Russian Language Pack — русификация интерфейса.
    • SFTP (автор Natizyskunk) — работа с файлами сайта по FTP/SFTP прямо из VS Code.
    • WordPress Snippets — автодополнение функций WordPress.
    • PHP Intelephense — интеллектуальная поддержка PHP.
    • Prettier — автоформатирование кода.
    • Auto Rename Tag — автоматическое переименование парных тегов.
    • Bracket Pair Colorizer — цветные скобки для наглядности.
  3. Для установки: найдите расширение в поиске и нажмите «Установить».

Шаг 3: Настройка внешнего вида

  1. Откройте настройки: Ctrl+, или «Файл → Параметры → Параметры».
  2. Настройте шрифт: найдите «Font Family» и укажите Consolas, 'Courier New', monospace.
  3. Размер шрифта: 14–16 для комфортной работы.
  4. Размер табуляции: 4 пробела (стандарт WordPress).
  5. Автосохранение: включите «Auto Save» — файлы будут сохраняться автоматически.
  6. Тема: выберите удобную. «Dark+» — классика.

4.3 Расширение SFTP — работа с файлами сайта прямо из редактора

Это расширение — killer feature VS Code для работы с WordPress. Вы можете редактировать файлы сайта, не переключаясь между FTP-клиентом и редактором.

Настройка SFTP

  1. Создайте локальную папку для проекта. Например, D:\Сайты\мой-сайт\.
  2. Откройте эту папку в VS Code: «Файл → Открыть папку».
  3. Откройте командную палитру: Ctrl+Shift+P.
  4. Введите SFTP: Config и выберите эту команду.
  5. В папке проекта появится файл sftp.json.
  6. Откройте его и заполните данными подключения:
{
    "name": "Мой сайт",
    "host": "ftp.ваш_домен.ru",
    "protocol": "ftp",
    "port": 21,
    "username": "ваш_логин",
    "password": "ваш_пароль",
    "remotePath": "/public_html",
    "context": "./",
    "uploadOnSave": true,
    "ignore": [
        ".vscode",
        ".git",
        ".DS_Store"
    ]
}
  1. Сохраните файл sftp.json.
  2. Откройте командную палитру (Ctrl+Shift+P).
  3. Введите SFTP: List All — увидите подключение.
  4. Нажмите на подключение — VS Code подключится к серверу.
  5. Нажмите «Download Project» — скачаются все файлы сайта.
⚠️ Осторожно с параметром uploadOnSave!
Если он включён (true), каждое сохранение файла на компьютере автоматически загружает его на сервер. Это удобно, но опасно: одна ошибка — и сайт «упадёт». Для новичков рекомендуем сначала выключить эту опцию (false) и загружать файлы вручную.

Как работать с SFTP-расширением

  • Скачать файл с сервера: правый клик в панели SFTP → Download.
  • Загрузить файл на сервер: правый клик на локальном файле → Upload.
  • Синхронизировать всю папку: правый клик → Sync Local → Remote.
  • Сравнить файлы: правый клик → Compare.
💡 Практический приём: Скачайте проект целиком, работайте с файлами локально, а потом загружайте изменения. Это быстрее и безопаснее, чем править файлы прямо на сервере.

4.4 Правила безопасной работы с кодом

Работа с кодом — это работа с «живым» сайтом. Одна ошибка может его обрушить. Соблюдайте эти правила — и вы сведёте риски к минимуму.

Правило 1: Всегда делайте резервную копию перед правкой

Перед правкой любого файла:

  1. Скачайте оригинальный файл на компьютер.
  2. Сделайте его копию с расширением .backup. Например, style.css → style.css.backup.
  3. Только после этого начинайте редактирование.

Правило 2: Правьте по одному файлу за раз

Не вносите изменения в 10 файлов одновременно. Если сайт «упадёт», вы не будете знать, из-за чего. Правьте один файл — проверяйте результат — переходите к следующему.

Правило 3: Не трогайте ядро и чужие плагины

Никогда не правьте файлы в wp-admin/, wp-includes/ и в чужих плагинах. Их изменения будут перезаписаны при обновлении. Для кастомизации используйте дочерние темы или собственные плагины.

Правило 4: Проверяйте код перед сохранением

В VS Code есть встроенная проверка синтаксиса PHP. Если есть ошибка — редактор подсветит её красным. Не сохраняйте файл, если видите красные подчёркивания!

Правило 5: Работайте на тестовой копии

Если возможно, создайте тестовую копию сайта (на поддомене или локально). Все опасные эксперименты проводите на ней. Только после успешной проверки переносите на боевой сайт.

⚠️ Золотое правило:
«Нет бэкапа — нет правки». Не начинайте редактирование, пока не сделали копию файла. Это займёт 10 секунд, но может спасти часы работы.

4.5 Практический пример: правим style.css темы безопасно

Ситуация: Нужно изменить цвет ссылок в теме на свой фирменный. Мы сделаем это через дочернюю тему (о ней подробно в главе 7), а пока — безопасно поправим файл style.css, чтобы понять процесс.

Пошаговое решение

  1. Подключитесь к сайту по SFTP через VS Code.
  2. Скачайте файл wp-content/themes/active-theme/style.css на компьютер.
  3. Сделайте копию файла: создайте style.css.backup рядом.
  4. Откройте style.css в VS Code.
  5. Найдите секцию для ссылок. Используйте поиск (Ctrl+F) по слову a {.
  6. Добавьте в конец файла новое правило:
/* Кастомный цвет ссылок */
a, a:visited {
    color: #0969da;
    text-decoration: none;
}

a:hover, a:focus {
    color: #0550ae;
    text-decoration: underline;
}
  1. Проверьте файл на ошибки. VS Code не должен подсвечивать красным.
  2. Сохраните файл (Ctrl+S).
  3. Загрузите файл на сервер через SFTP (правый клик → Upload).
  4. Обновите сайт в браузере. Ссылки должны измениться.
  5. Проверьте на телефоне.
✅ Результат: Вы безопасно отредактировали файл темы, имея резервную копию. Если что-то пойдёт не так — просто вернёте style.css.backup обратно.

Что делать, если сайт «упал»

  1. Не паникуйте.
  2. Верните файл из бэкапа: загрузите style.css.backup на сервер, переименовав его в style.css.
  3. Обновите сайт. Если он заработал — вы восстановили всё за 30 секунд.
  4. Проанализируйте ошибку — что вы сделали не так?
  5. Попробуйте снова, более внимательно.

4.6 Полезные функции VS Code для работы с WordPress

Поиск по проекту

Одна из самых мощных функций. Нажмите Ctrl+Shift+F и введите любой текст — вы найдёте его во всех файлах проекта. Это незаменимо при поиске проблемной строки кода.

Автодополнение WordPress

С расширением WordPress Snippets VS Code автоматически дополняет функции WordPress. Начните вводить wp_ — увидите список функций.

Форматирование кода

Расширение Prettier автоматически форматирует код. Нажмите Shift+Alt+F — код станет аккуратным и читаемым.

Мини-карта файла

Справа в VS Code есть мини-карта — уменьшенная копия файла. Она помогает быстро ориентироваться в больших файлах.

Сравнение файлов

Если вы не уверены, что изменилось в файле, откройте командную палитру (Ctrl+Shift+P) и введите Compare Active File With.... Выберите файл для сравнения — VS Code подсветит различия.

4.7 Решение типичных проблем

Проблема Причина Решение
VS Code не открывает PHP-файлы с подсветкой Не установлено расширение PHP Установите «PHP Intelephense» через панель расширений
SFTP не подключается Неверные данные или порт Проверьте sftp.json: host, username, password, port, protocol
Файл не загружается на сервер Недостаточно прав Проверьте права на папку (должно быть 755) и файл (644)

VS Code тормозит Слишком много расширений Отключите неиспользуемые расширения

4.9 Часто задаваемые вопросы

  • Можно ли использовать бесплатный Notepad++ вместо VS Code? Да, для простых правок его достаточно. Но для серьёзной работы VS Code удобнее: встроенный терминал, расширения, работа с FTP.
  • Нужно ли знать программирование, чтобы пользоваться VS Code? Нет. VS Code — это текстовый редактор. Даже если вы просто копируете и вставляете готовый код, редактор с подсветкой синтаксиса снижает риск ошибок.
  • Как быть, если я случайно удалил файл через SFTP? Если есть резервная копия — восстановите. Если нет — скачайте оригинал из архива WordPress (для файлов ядра) или из репозитория GitHub темы/плагина.
  • Что делать, если VS Code не видит PHP-файлы как PHP? Проверьте, что установлено расширение PHP Intelephense. Если нет — установите.
  • Можно ли редактировать файлы сайта прямо из VS Code без скачивания? Да, если у вас настроен SFTP и параметр uploadOnSave: true. Но для новичков это опасно — можно случайно испортить файл на сервере.
  • Как сравнить два файла в VS Code? Откройте первый файл, нажмите Ctrl+Shift+P, введите Compare Active File With..., выберите второй файл.
  • Что делать, если в коде появились «кракозябры»? Проверьте кодировку файла: должна быть UTF-8 без BOM. В VS Code: «Вид → Палитра команд → Изменить кодировку файла».
  • Какое расширение выбрать для работы с FTP? «SFTP» от Natizyskunk — самое популярное и активное обновляемое.
