🎨 Работа с кодом и дополнительными стилями: полный разбор

В WordPress есть несколько способов добавить свой CSS-код. Для блочных тем (Twenty Twenty-Five) основной путь — через Редактор сайта. Это безопасный способ: ваши изменения не затрагивают файлы темы и не пропадут при её обновлении.

Где найти «Дополнительные CSS»

  1. В админ-панели перейдите в «Внешний вид» → «Редактор».
  2. В левой панели нажмите на иконку «Стили» (чёрно-белый круг).
  3. Выберите раздел «Дополнительные CSS».
  4. Введите CSS-правила — они применятся ко всему сайту.

Как это работает

Вы вводите CSS-правила, и они применяются ко всему сайту. Это безопасный способ, потому что ваши изменения не затрагивают файлы темы и не пропадут при её обновлении.

Для отдельного блока

  1. Создайте CSS-класс в «Дополнительных стилях».
  2. В редакторе страницы выберите нужный блок.
  3. Откройте раздел «Дополнительно» в правой панели.
  4. Впишите имя класса в поле «Дополнительный CSS-класс(ы)».

Правила безопасности

Важно: перед любыми экспериментами с кодом всегда делайте резервную копию сайта. Это убережёт от потери данных, если что-то пойдёт не так.

☁️ Заливка файлов на Google Диск и их использование в WordPress

Да, это возможно, но напрямую «подтащить» файл из Google Диска в медиабиблиотеку WordPress нельзя — нужно либо импортировать его, либо использовать специальный плагин.

Самый простой способ — плагины импорта

Michael Cloud Image Auto Importer

Этот плагин позволяет подключаться к вашему Google Диску и массово импортировать изображения прямо в медиабиблиотеку WordPress. Он умеет импортировать целые папки, а также автоматически создавать alt-тексты на основе имён файлов для лучшего SEO. Для подключения не нужны сложные API-ключи, достаточно авторизовать аккаунт Google.

KFX Media Importer for Google Drive

Ещё один плагин с похожим функционалом, который также позволяет импортировать изображения из Google Диска в стандартную медиатеку.

Альтернативный подход — через формы

Если вы хотите, чтобы посетители могли сами загружать файлы на ваш Google Диск, можно использовать плагины форм, например, Formidable Forms. Вы создаёте форму, и при её отправке файл автоматически сохраняется в указанную папку на Google Диске.

🤖 Скрипты для пакетной загрузки и автоматизации

Да, такие скрипты существуют. Это более продвинутый уровень работы, но он очень эффективен для больших объёмов.

Основной инструмент — WP-CLI

WP-CLI (WordPress Command Line Interface) — это интерфейс командной строки для управления WordPress. С его помощью можно выполнять массовые операции без захода в админ-панель.

Пример команды для загрузки:

wp media import /path/to/images/*.jpg --title="Bulk Upload"

Эта команда загрузит все JPG-файлы из указанной папки в медиабиблиотеку.

Для продвинутых пользователей

Можно писать собственные скрипты (например, на PHP или Python), которые будут взаимодействовать с WordPress через REST API или WP-CLI. Это позволяет автоматизировать практически любые задачи: от обновления записей до массовой загрузки и оптимизации файлов.

Готовые плагины для пакетной загрузки

Если не хочется работать с командной строкой, есть плагины, которые делают то же самое через удобный интерфейс:

  • Nifa Bulk Media Uploader — позволяет загружать изображения и видео, упакованные в ZIP-архив. Плагин сам распакует архив и добавит все файлы в медиабиблиотеку.
  • MediaNest Upload Manager — ещё один плагин для пакетной загрузки файлов и папок в медиатеку WordPress.

🛡️ Почему важно уметь восстанавливать сайт

Восстановление сайта — навык, который спасает проекты

Сайты «рушатся» по разным причинам: неудачное обновление плагина, конфликт темы, ошибка в коде, взлом, сбой на хостинге, случайное удаление файла. Без резервной копии восстановление может занять дни. С правильным подходом — не более часа.

В этом курсе мы освоим:

  • Как правильно делать резервные копии файлов и базы данных.
  • Как восстановить сайт из бэкапа через FTP и phpMyAdmin.
  • Как восстановить доступ к админке, если сайт не открывается.
  • Как откатить проблемное обновление.
  • Как предотвратить будущие сбои.
