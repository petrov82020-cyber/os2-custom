Глава 6: Дополнительные стили WordPress — Site Editor, классы, плагины

✍️ Время чтения: ~32 минуты | 🎯 Цель: освоить все способы добавления CSS в WordPress и научиться точечно стилизовать отдельные блоки

В предыдущей главе мы изучили CSS как язык. Теперь пришло время узнать, как именно применять CSS в WordPress. В системе есть несколько способов добавить свои стили — от встроенного редактора до плагинов. Мы разберём каждый способ, научимся создавать CSS-классы для отдельных блоков и применять стили точечно, не затрагивая остальной сайт.

💡 Главный принцип:
В WordPress есть глобальные стили (действуют на весь сайт) и точечные стили (действуют на конкретный блок). Глобальные стили мы настраиваем через Site Editor → Стили. Точечные — через CSS-классы, которые назначаются отдельным блокам. Понимание этой разницы — ключ к аккуратному дизайну.

6.1 Три способа добавления CSS в WordPress

В WordPress существует три основных способа добавить собственные стили. Каждый имеет свои преимущества и подходит для разных задач.

Рекомендуем
🎨
Дополнительные CSS в Site Editor Встроенный редактор для блочных тем. Изменения не затрагивают файлы темы, сохраняются при обновлении. Самый безопасный способ.
  • Работает для всех блочных тем
  • Простой интерфейс
  • Мгновенный результат
  • Не требует FTP
📁
Дочерняя тема Создание отдельной темы-наследника. Для продвинутых пользователей. Полный контроль, но сложнее в настройке.
  • Полный контроль над CSS
  • Работает для любых тем
  • Требует FTP или файловый менеджер
  • Нужны базовые знания PHP
🔌
Плагины для CSS Дополнительные плагины, добавляющие отдельную страницу для CSS. Удобно, если не хотите использовать Site Editor.
  • Simple Custom CSS
  • WP Add Custom CSS
  • Code Snippets (для CSS+PHP)
  • Работает с любыми темами
💡 Какой способ выбрать:
Для блочных тем (Twenty Twenty-Five и другие) используйте «Дополнительные CSS» — это самый простой и безопасный путь. Для классических тем или если нужен полный контроль — создайте дочернюю тему. Если не хотите разбираться с Site Editor — установите плагин.

6.2 Дополнительные CSS в Site Editor — пошаговый разбор

Это основной способ для блочных тем. Изменения применяются ко всему сайту, но не затрагивают файлы темы.

Как открыть «Дополнительные CSS»

  1. Войдите в админ-панель WordPress.
  2. Перейдите в «Внешний вид → Редактор». Откроется Редактор сайта (Site Editor).
  3. В левой панели нажмите на иконку «Стили» (чёрно-белый круг).
  4. Нажмите на три точки (⋮) рядом с заголовком «Стили».
  5. В выпадающем меню выберите «Дополнительные CSS».
  6. Откроется окно редактора CSS.

Интерфейс редактора CSS

Редактор «Дополнительные CSS» прост:

  • Текстовое поле — здесь вы пишете CSS-правила.
  • Кнопка «Сохранить» внизу — сохраняет изменения.
  • Живой предпросмотр — изменения применяются мгновенно, но без сохранения.

Практический пример: изменение цвета всех ссылок

  1. Откройте «Дополнительные CSS».
  2. Введите код:
/* Меняем цвет всех ссылок на сайте */
a {
    color: #0969da;
    text-decoration: none;
    transition: color 0.3s ease;
}

a:hover {
    color: #0550ae;
    text-decoration: underline;
}
  1. Нажмите «Сохранить».
  2. Откройте сайт в новой вкладке. Все ссылки стали синими, при наведении — темнеют и подчёркиваются.
✅ Готово! Вы добавили глобальные стили для ссылок. Это изменение применится ко всем ссылкам на сайте — в меню, тексте, кнопках.

6.3 Создание CSS-классов для отдельных блоков

Глобальные стили — это мощно, но иногда нужно изменить только один конкретный блок, не затрагивая остальные. Для этого используются CSS-классы.

Как это работает

  1. Вы создаёте CSS-правило с классом в «Дополнительных CSS».
  2. Затем назначаете этот класс конкретному блоку в редакторе.
  3. Стиль применяется только к этому блоку.

Пошаговая инструкция

Шаг 1: Создайте CSS-класс

  1. Откройте «Дополнительные CSS».
  2. Добавьте правило с уникальным классом. Название класса должно начинаться с точки. Используйте латиницу, без пробелов.
/* Стиль для блока с предупреждением */
.my-warning-box {
    background-color: #fff3e3;
    border-left: 5px solid #f97316;
    padding: 20px 25px;
    border-radius: 12px;
    font-size: 16px;
    color: #78350f;
}

Шаг 2: Назначьте класс блоку

  1. Откройте страницу в редакторе (Страницы → нужная страница).
  2. Выделите блок, к которому хотите применить стиль.
  3. В правой панели перейдите на вкладку «Дополнительно».
  4. Найдите поле «Дополнительный CSS-класс(ы)».
  5. Введите название класса без точки: my-warning-box.
  6. Нажмите «Обновить».
  7. Откройте страницу на сайте — блок получил свой уникальный стиль.
Результат применения класса
⚠️ Внимание! Это пример блока с классом my-warning-box. Стиль применён только к этому блоку, остальные блоки не изменились.
💡 Преимущество классов:
Один и тот же класс можно назначить нескольким блокам. Например, создайте класс .my-cta-block и назначьте его всем призывам к действию на сайте. Изменение стиля в CSS автоматически обновит все эти блоки.

6.5 Использование инструментов разработчика для точной настройки

Как узнать, какой класс у конкретного блока или какой стиль применяется к элементу? Ответ — инструменты разработчика (DevTools). Мы уже кратко касались их в главе 5, теперь разберём подробно.

Пошаговая инструкция

  1. Откройте сайт в браузере (Chrome, Firefox, Edge).
  2. Нажмите F12 или правой кнопкой → «Исследовать элемент».
  3. Нажмите на иконку со стрелкой в левом верхнем углу панели (или Ctrl+Shift+C).
  4. Наведите курсор на нужный элемент — он подсветится синим.
  5. Кликните на элемент. В панели откроется его HTML-код.
  6. Изучите классы элемента. Они указаны в атрибуте class="...". Например, class="wp-block-button__link my-custom-btn".
  7. Справа (или снизу) во вкладке Styles вы увидите все CSS-правила, которые применяются к элементу. Здесь можно увидеть, какое правило «побеждает».
  8. Здесь же можно тестировать изменения: меняйте цвета, размеры, отступы — и сразу видите результат. Это не сохраняется на сайте, но помогает подобрать нужные значения.
💡 Практический приём: Найдите элемент, который хотите стилизовать. Скопируйте его классы через DevTools. Вернитесь в «Дополнительные CSS». Напишите правило с этими классами. Сохраните. Проверьте результат на сайте.

Пример: находим и стилизуем конкретную кнопку

  1. Откройте страницу с кнопкой.
  2. F12 → выберите кнопку.
  3. Видите HTML: <a class="wp-block-button__link has-background" style="background-color:#f97316">Купить</a>.
  4. Обратите внимание: у кнопки есть класс has-background и инлайн-стиль.
  5. В «Дополнительных CSS» создайте правило с более специфичным селектором:
/* Стилизуем кнопки с классом has-background */
.wp-block-button__link.has-background {
    box-shadow: 0 4px 15px rgba(249,115,22,0.4);
    transition: transform 0.3s ease;
}

.wp-block-button__link.has-background:hover {
    transform: translateY(-3px);
}
  1. Сохраните.
  2. Проверьте на сайте. Кнопки с этим классом «приподнимаются» при наведении.

6.6 Плагины для дополнительных CSS

Если вы не хотите использовать Site Editor или работаете с классической темой, установите плагин для CSS. Вот лучшие варианты.

Simple Custom CSS

Простой и надёжный плагин. Добавляет отдельную страницу «Внешний вид → Простой CSS» с редактором кода.

  1. Установите плагин: «Плагины → Добавить новый → Simple Custom CSS».
  2. Активируйте.
  3. Перейдите в «Внешний вид → Простой CSS».
  4. Введите CSS-правила.
  5. Нажмите «Обновить простой CSS».

WP Add Custom CSS

Более функциональный плагин. Позволяет добавлять CSS для отдельных страниц и записей.

Code Snippets

Плагин для добавления не только CSS, но и PHP, JavaScript. Мощный инструмент для продвинутых пользователей.

💡 Когда использовать плагин, а когда — «Дополнительные CSS»:
Для блочных тем — «Дополнительные CSS» (проще, безопаснее). Для классических тем — плагин или дочерняя тема. Если нужно много CSS-кода и организация по страницам — плагин.

6.7 Практический пример: создаём блок с предупреждением

Давайте соберём всё вместе. Создадим кастомный блок с предупреждением, который можно вставлять на разные страницы.

Задача

  • Фон: светло-жёлтый (#fff8e6).
  • Левая граница: оранжевая (#f97316), 5px.
  • Отступы: 20px.
  • Скругление: 12px.
  • Иконка в начале (эмодзи).

Пошаговое решение

  1. Откройте «Дополнительные CSS».
  2. Создайте класс .my-warning:
.my-warning {
    background-color: #fff8e6;
    border-left: 5px solid #f97316;
    padding: 20px 25px;
    border-radius: 12px;
    font-size: 16px;
    color: #78350f;
    margin: 20px 0;
}

.my-warning::before {
    content: "⚠️ ";
    font-size: 1.2em;
    margin-right: 8px;
}
  1. Сохраните.
  2. Откройте страницу в редакторе.
  3. Создайте блок «Группа» или «Абзац».
  4. Выделите блок → Дополнительно → «Дополнительный CSS-класс».
  5. Введите: my-warning.
  6. Внутри блока напишите текст предупреждения.
  7. Обновите страницу.
  8. Откройте на сайте — блок выглядит как стилизованное предупреждение с иконкой.
Результат
⚠️ Важное предупреждение! Этот блок стилизован через CSS-класс .my-warning. Такой подход позволяет вставлять одинаково оформленные блоки на разные страницы.

6.8 Практический пример: точечная стилизация кнопки на одной странице

Ситуация: Нужно изменить стиль кнопки только на одной странице, не затрагивая другие.

Пошаговое решение

  1. Откройте «Дополнительные CSS».
  2. Создайте класс .btn-orange:
.btn-orange {
    background-color: #f97316 !important;
    color: #ffffff !important;
    padding: 15px 40px !important;
    border-radius: 30px !important;
    font-weight: 700 !important;
    box-shadow: 0 6px 20px rgba(249,115,22,0.4) !important;
}

.btn-orange:hover {
    background-color: #ea580c !important;
    transform: translateY(-3px);
}
  1. Сохраните.
  2. Откройте нужную страницу в редакторе.
  3. Выделите кнопку.
  4. В панели «Дополнительно» → «Дополнительный CSS-класс» введите: btn-orange.
  5. Обновите страницу.
  6. Откройте страницу на сайте. Кнопка стала оранжевой и «приподнимается» при наведении.
⚠️ По поводу !important:
В этом примере мы использовали !important, потому что WordPress добавляет инлайн-стили к кнопкам (цвет фона из настроек блока). Чтобы перебить инлайн-стиль, нужен !important. Это один из немногих случаев, когда его использование оправдано.

6.9 Решение типичных проблем

Проблема Причина Решение
CSS-класс не применяется к блоку Опечатка в названии класса или он не назначен блоку Проверьте название в «Дополнительных CSS» и в поле «Дополнительный CSS-класс». Они должны совпадать
Стиль применяется ко всем блокам, а не к одному Селектор слишком общий Используйте класс вместо тега. Например, .my-btn вместо a
Стиль не перебивает стили темы Специфичность ниже Добавьте !important или используйте более специфичный селектор
Не вижу поле «Дополнительный CSS-класс» Не открыта вкладка «Дополнительно» Выделите блок → правая панель → вкладка «Дополнительно» → поле внизу
CSS «слетел» после обновления темы CSS был в файлах темы Перенесите правила в «Дополнительные CSS» или дочернюю тему
Изменения не видны на сайте Кэш браузера или сайта Очистите кэш (Ctrl+F5) и кэш-плагина
В Site Editor нет «Дополнительные CSS» Тема не поддерживает FSE Используйте плагин Simple Custom CSS или дочернюю тему
Класс не сохраняется в блоке Поле пустое или содержит пробелы Введите название класса без точки и пробелов. Для нескольких классов — через пробел

6.11 Часто задаваемые вопросы

  • Чем отличается «Дополнительные CSS» от «Дополнительный CSS-класс»? «Дополнительные CSS» — это общий редактор стилей для всего сайта. «Дополнительный CSS-класс» — это поле в настройках блока, куда вы вписываете имя класса, чтобы применить к нему стиль.
  • Можно ли назначить несколько классов одному блоку? Да, через пробел: my-class another-class. В CSS будут применяться правила обоих классов.
  • Где хранятся CSS-классы? В «Дополнительных CSS» в базе данных WordPress. Они не затрагивают файлы темы.
  • Что делать, если класс не работает? Проверьте через DevTools, есть ли класс в HTML-коде элемента. Возможно, вы не сохранили изменения или ошиблись в названии.
  • Можно ли использовать CSS для скрытия элементов? Да. Например, .my-class { display: none; } скроет блок.
  • Нужно ли использовать !important? Только в крайнем случае — когда нужно перебить инлайн-стиль или стиль с более высокой специфичностью.
  • Как проверить, какие CSS-правила применяются к элементу? Откройте DevTools, выберите элемент, посмотрите вкладку Styles — там показаны все активные правила.
  • Можно ли добавлять CSS через плагин, если используешь блочную тему? Да, но «Дополнительные CSS» удобнее — они встроены. Плагин нужен, если вы хотите организовать CSS по страницам или использовать дополнительный функционал.
  • Что делать, если сайт «упал» после добавления CSS? Откройте «Дополнительные CSS» через админку (если она работает) или через FTP (файл темы). Удалите последнее правило и сохраните. Если админка не работает — восстановите сайт из бэкапа.
