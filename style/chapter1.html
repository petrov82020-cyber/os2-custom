Глава 1: Введение — темы, шаблоны, паттерны и стили

✍️ Время чтения: ~20 минут | 🎯 Цель: разобраться в основных понятиях современного WordPress и понять, как они связаны между собой

Добро пожаловать в первую главу курса! Прежде чем мы начнём что-то менять и настраивать, нужно разобраться в терминологии. Тема, шаблон, паттерн, стиль — эти четыре понятия часто путают, но они означают разные вещи. Понимание их различий — основа для всей дальнейшей работы.

💡 Главная идея курса: Современный WordPress (начиная с версии 5.9) работает по принципу Full Site Editing (FSE) — полное редактирование сайта. Вы можете менять не только контент страниц, но и весь внешний вид сайта — прямо из админки, без правки кода. Но чтобы использовать эту возможность, нужно понимать, из каких «кирпичиков» состоит сайт.

1.1 Что такое тема WordPress

Тема — это полный набор файлов, который определяет внешний вид и функциональность всего вашего сайта. Она включает в себя все стили, шаблоны, скрипты и изображения. Проще говоря, тема — это «одежда» для вашего сайта, которая задаёт общий стиль, но не влияет на содержание.

Когда вы устанавливаете WordPress, автоматически активируется одна из тем по умолчанию. Меняя тему, вы полностью меняете внешний вид сайта — но все ваши записи, страницы и медиафайлы остаются на месте.

Что входит в тему

  • Шаблоны: структура для разных типов страниц (главная, запись блога, архив, страница 404 и т. д.).
  • Стили: цвета, шрифты, отступы, макет — визуальное оформление.
  • Файлы функций: PHP-файл functions.php, который добавляет функциональность.
  • Скриншот: превью темы, которое отображается в админке.
  • Паттерны: готовые секции контента, входящие в состав темы.

Блочные и классические темы

Сегодня все темы делятся на два больших класса:

❌ Классические темы

  • Используют «Настройщик» (Customizer) для изменения внешнего вида
  • Шаблоны — это PHP-файлы, которые нужно править в коде
  • Ограниченные возможности настройки без программирования
  • Не поддерживают полное редактирование сайта
  • Примеры: Twenty Twenty-One, Astra, OceanWP

✅ Блочные темы (FSE)

  • Используют Редактор сайта для всего
  • Шаблоны — это HTML-файлы, редактируемые визуально
  • Полный контроль над дизайном без кода
  • Поддерживают паттерны, глобальные стили, шаблоны
  • Примеры: Twenty Twenty-Three, Twenty Twenty-Four, Twenty Twenty-Five
⚠️ Важно: В этом курсе мы работаем только с блочными темами. Если у вас установлена классическая тема, часть инструментов, которые мы будем изучать (Редактор сайта, паттерны, глобальные стили), будет недоступна. Рекомендуем переключиться на одну из тем по умолчанию WordPress — об этом мы поговорим во второй главе.

1.2 Что такое шаблон (Template)

Шаблон — это структурная основа для определённого типа страниц вашего сайта. Он определяет, какие элементы и в каком порядке будут отображаться на странице. Думайте о нём как о чертеже или каркасе здания.

Как это работает

В блочных темах шаблоны — это HTML-файлы, которые состоят из блоков и паттернов. Например:

  • Есть шаблон для главной страницы — он определяет, что сначала идёт Hero-секция, потом блок преимуществ, потом отзывы.
  • Есть шаблон для отдельной записи блога — он показывает заголовок, дату, автора, контент, комментарии.
  • Есть шаблон для страницы «Контакты» — с картой и формой.

Где искать шаблоны

Все шаблоны темы можно увидеть и отредактировать в Редакторе сайта:

  1. Войдите в админ-панель WordPress.
  2. Перейдите в «Внешний вид» → «Редактор».
  3. В левой панели выберите раздел «Шаблоны».
  4. Нажмите на любой шаблон — откроется его структура из блоков.
  5. Вы можете редактировать любой блок так же, как при редактировании обычной страницы.

Примеры шаблонов

Шаблон Для чего используется
Index / Главная страница Основной шаблон для отображения главной страницы сайта.
Page (Страница) Шаблон для обычных статических страниц: «О нас», «Услуги», «Контакты».
Single Post (Запись) Шаблон для отображения отдельной записи блога.
Archive (Архив) Шаблон для страниц архивов: список записей по дате, категории, автору.
Search (Поиск) Шаблон для страницы результатов поиска по сайту.
404 Шаблон для страницы «Не найдено».
💡 Полезная аналогия:
Представьте, что сайт — это дом. Тема — это архитектурный стиль (модерн, классика, хай-тек). Шаблон — это чертёж конкретной комнаты (гостиной, кухни, спальни). Паттерн — это готовый предмет мебели (диван, шкаф), который можно поставить в любую комнату.

1.3 Что такое паттерн (Pattern)

Паттерн — это готовый блок контента, который можно вставить на страницу и настроить под себя. Паттерн — это не весь каркас страницы, а её отдельная секция: например, красивый заголовок с кнопкой, галерея изображений, блок с отзывами или раздел с ценами.

Как это работает

Вы просто перетаскиваете паттерн из специальной библиотеки в нужное место на странице — и он появляется со всем своим оформлением. После этого вы можете изменить текст, картинки и цвета, но структура останется.

Где искать паттерны

  1. Откройте любую страницу в блочном редакторе (Страницы → Добавить новую).
  2. Нажмите на значок «+» для добавления блока.
  3. Переключитесь на вкладку «Паттерны» (Patterns).
  4. Изучите доступные категории:
    • Featured (Рекомендуемые) — лучшие паттерны от WordPress.
    • Text (Текст) — заголовки, абзацы, списки.
    • Call to Action (Призыв) — секции с кнопками.
    • Banners (Баннеры) — Hero-секции.
    • Services (Услуги) — блоки с описанием услуг.
    • Testimonials (Отзывы) — блоки с цитатами клиентов.
    • Pricing (Цены) — таблицы с тарифами.
    • Team (Команда) — секции с сотрудниками.
  5. Нажмите на паттерн — он вставится на страницу.

Отличия паттернов от шаблонов

Характеристика Шаблон Паттерн
Что это Весь каркас страницы Отдельная секция
Пример «Страница блога» «Секция с последними записями»
Где применяется Для типа страниц (все записи блога, все страницы) Для конкретного места на странице
Настраивается В Редакторе сайта → Шаблоны В блочном редакторе → Паттерны
Иерархия Верхний уровень Внутри шаблона или страницы
⚠️ Не путайте! Шаблон — это весь каркас страницы. Паттерн — это готовая секция для этого каркаса. Шаблон можно представить как «пустую страницу с разметкой», а паттерн — как «готовый блок, который вставляется в эту разметку».

1.4 Что такое стиль (Style)

Стиль — это визуальные параметры, которые применяются ко всему сайту: цвета, шрифты, отступы, макет. Стили настраиваются в Редакторе сайта в разделе «Стили» (Styles) и применяются глобально — то есть меняют внешний вид сразу везде.

Что можно настроить в стилях

  • Цвета: основная палитра, фоны, текст, ссылки, кнопки.
  • Типографика: шрифты для заголовков, основного текста, ссылок, кнопок.
  • Макет: ширина контента, отступы, промежутки.
  • Границы: скругления, толщина, цвет.
  • Тени: тени для блоков и кнопок.

Как настроить глобальные стили

  1. Перейдите в «Внешний вид» → «Редактор».
  2. В левой панели выберите раздел «Стили».
  3. Откройте нужную категорию: «Цвета», «Типографика», «Макет».
  4. Измените параметры. Все изменения применяются мгновенно ко всему сайту.
  5. Нажмите «Сохранить».
💡 Преимущество глобальных стилей:
Вместо того чтобы менять цвет каждой кнопки вручную, вы меняете один цвет в глобальных стилях — и все кнопки на сайте обновляются автоматически. Это называется «дизайн-система» и является стандартом современной веб-разработки.

1.5 Как всё это связано: иерархия понятий

Чтобы окончательно закрепить понимание, представим иерархию:

🎨 Тема (Theme)
├── 🧱 Шаблоны (Templates)
│ ├── Главная страница (Index)
│ ├── Страница (Page)
│ ├── Запись (Single Post)
│ └── Архивы, поиск, 404
├── 🧩 Части шаблона (Template Parts)
│ ├── Шапка (Header)
│ └── Подвал (Footer)
├── 📦 Паттерны (Patterns)
│ ├── Hero-секции
│ ├── Блоки с ценами
│ └── Отзывы, команда, FAQ
└── 🖌️ Стили (Styles)
├── Цвета
├── Типографика
└── Макет

Тема — это контейнер верхнего уровня. Внутри неё находятся шаблоны (каркасы страниц), части шаблона (глобальные элементы), паттерны (готовые секции) и стили (визуальные настройки). Все эти элементы работают вместе, создавая целостный сайт.

1.6 Практические примеры: как всё работает вместе

Пример 1: Сайт-визитка компании

  1. Тема: Twenty Twenty-Five.
  2. Шаблоны: главная страница (Hero + преимущества + услуги + контакты), страница «О нас», страница «Услуги», страница «Контакты».
  3. Части шаблона: шапка с логотипом и меню, подвал с копирайтом и контактами.
  4. Паттерны: вставляем готовые блоки для Hero, преимуществ, отзывов.
  5. Стили: настраиваем синий цвет бренда, шрифт Montserrat для заголовков, Open Sans для текста.

Пример 2: Блог о путешествиях

  1. Тема: Twenty Twenty-Four.
  2. Шаблоны: главная страница с лентой записей, шаблон отдельной записи с большой картинкой, архив по категориям.
  3. Части шаблона: шапка с меню категорий, подвал со ссылками на соцсети.
  4. Паттерны: галерея фотографий, блок «Похожие записи», блок подписки на рассылку.
  5. Стили: тёплые тона, шрифт PT Serif для текста, крупные заголовки для акцента.

Пример 3: Лендинг курса

  1. Тема: Twenty Twenty-Five.
  2. Шаблоны: только главная страница-лендинг с последовательными секциями.
  3. Части шаблона: минимальная шапка (лого + кнопка), минимальный подвал.
  4. Паттерны: используем как можно больше готовых блоков из библиотеки.
  5. Стили: яркий акцентный цвет, крупный H1, чёткие CTA-кнопки.

1.7 Практическое задание: изучаем свою тему

📝 Задание для самопроверки

Часть 1: Узнайте свою тему
1. Войдите в админ-панель WordPress.
2. Перейдите в «Внешний вид» → «Темы».
3. Посмотрите, какая тема активна. Запишите её название.
4. Определите, является ли она блочной (поддерживает ли FSE).

Часть 2: Изучите шаблоны
5. Перейдите в «Внешний вид» → «Редактор».
6. Откройте раздел «Шаблоны».
7. Нажмите на шаблон «Главная страница» (Index).
8. Запишите, из каких блоков он состоит (например: Header, Post Content, Footer).
9. Посмотрите ещё 2–3 шаблона — сравните их структуру.

Часть 3: Изучите паттерны
10. Создайте новую страницу в WordPress.
11. Нажмите «+» для добавления блока.
12. Переключитесь на вкладку «Паттерны».
13. Просмотрите 5–7 паттернов из разных категорий.
14. Вставьте один паттерн на страницу.
15. Измените в нём текст и цвет кнопки.
16. Удалите страницу (не сохраняйте изменения).

Часть 4: Изучите стили
17. Перейдите в «Внешний вид» → «Редактор» → «Стили».
18. Откройте раздел «Цвета».
19. Посмотрите, какие цвета заданы в палитре.
20. Откройте раздел «Типографика» и посмотрите, какие шрифты используются.
21. Ничего не меняйте — просто изучите.
✅ Что вы освоили: Основные понятия современного WordPress — тему, шаблон, паттерн и стиль. Вы поняли, как они связаны между собой, и увидели их в реальной админке. Теперь у вас есть база для дальнейшего изучения.

1.8 Часто задаваемые вопросы

  • Чем отличается тема от шаблона? Тема — это весь «набор одежды» сайта, включающий шаблоны, стили, функции. Шаблон — это «чертёж» конкретной страницы или типа страниц, который входит в тему.
  • Можно ли использовать паттерны из одной темы в другой? Да, если паттерны сохранены в общей библиотеке WordPress. Но паттерны, встроенные в конкретную тему, могут не отображаться при смене темы.
  • Что такое FSE и зачем он нужен? Full Site Editing — это технология, которая позволяет редактировать весь сайт (включая шапку, подвал, шаблоны) визуально, без кода. Это делает WordPress доступнее для новичков.
  • Нужно ли знать HTML/CSS для работы с блочными темами? Нет, для базовых задач достаточно визуального редактора. Знание CSS может пригодиться для тонкой настройки, но не обязательно.
  • Можно ли смешивать классические и блочные темы? Нет, это разные подходы. Если вы работаете с FSE, используйте блочную тему. Если хотите использовать «Настройщик» — классическую.
  • Где хранятся паттерны, которые я создал? В разделе «Внешний вид» → «Паттерны» (или в «Редакторе сайта» → «Паттерны»). Их можно использовать на любой странице сайта.
