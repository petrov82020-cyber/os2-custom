Глава 5: Шаблоны (Templates) — структура и редактирование

✍️ Время чтения: ~28 минут | 🎯 Цель: освоить работу с шаблонами WordPress — от просмотра до создания собственных макетов для разных типов страниц

В предыдущей главе мы познакомились с Редактором сайта и узнали, что одним из его главных разделов является «Шаблоны». Теперь пришло время разобраться с ними подробно. Шаблоны — это «скелет» вашего сайта, определяющий структуру каждой страницы. Понимание шаблонов — ключ к созданию профессионального сайта, где каждый тип контента имеет свой подходящий макет.

💡 Что такое шаблон?
Шаблон (Template) — это структурная основа для определённого типа страниц. Он определяет, какие элементы и в каком порядке отображаются: где находится шапка, где — контент, где — подвал, есть ли боковая панель, какие блоки выводятся до и после основного контента. Каждый шаблон применяется к определённому типу записей или страниц.

5.1 Иерархия шаблонов WordPress

WordPress использует систему, которая автоматически выбирает подходящий шаблон для каждого запроса. Это называется иерархией шаблонов. Понимание этой системы поможет вам точно контролировать, какой шаблон применяется к какой странице.

Как работает иерархия

Когда пользователь открывает страницу, WordPress идёт по «цепочке» и выбирает наиболее подходящий шаблон. Чем специфичнее шаблон, тем выше его приоритет. Если специфичного шаблона нет — используется более общий.

📄 Обычная страница (Page)
├── Кастомный шаблон страницы (если назначен вручную)
├── page-{slug}.html (например, page-o-nas.html)
├── page-{id}.html (например, page-42.html)
└── page.html ← основной шаблон для всех страниц
📝 Отдельная запись (Single Post)
├── single-post-{slug}.html
├── single-post.html
├── single.html
└── index.html
📚 Архив (Archive)
├── category-{slug}.html
├── category.html
├── archive.html
└── index.html
🌐 Главная страница
├── front-page.html
├── home.html
└── index.html
💡 Практический вывод:
Вам не нужно создавать все возможные шаблоны. Достаточно тех, которые действительно нужны. Например, если у вас сайт-визитка, хватит трёх шаблонов: front-page (главная), page (обычные страницы), 404 (страница «не найдено»). Остальные WordPress подтянет автоматически.

5.2 Какие шаблоны есть в блочной теме

Когда вы активируете блочную тему, она предоставляет набор готовых шаблонов. Давайте разберём, за что отвечает каждый из них.

🏠
Index Основной шаблон по умолчанию. Используется, если для запроса нет более специфичного шаблона.
🎯
Front Page Шаблон для главной страницы сайта. Применяется, когда в настройках чтения выбрана «статическая главная».
📰
Home Шаблон для страницы со списком последних записей (если главная показывает блог).
📄
Page Шаблон для всех обычных страниц: «О нас», «Услуги», «Контакты».
📝
Single Шаблон для отдельной записи блога: заголовок, дата, автор, контент, комментарии.
📚
Archive Шаблон для архивов: список записей по категориям, меткам, датам, авторам.
🔍
Search Шаблон для страницы результатов поиска по сайту.
🚫
404 Шаблон для страницы «Не найдено» — когда запрошенная страница отсутствует.
🖼️
Attachment Шаблон для отображения отдельного медиафайла (изображения, видео).
👤
Author Шаблон для страниц авторов блога со списком их записей.
📅
Date Шаблон для архивов по датам (месяц, год).
📋
Blank Пустой шаблон — используется как основа для создания собственных макетов.
⚠️ Не все шаблоны нужно редактировать!
Некоторые шаблоны, например Index, используются как «резервные». Если вы измените Index, это может повлиять на многие страницы сайта. Начинайте с конкретных шаблонов (Front Page, Page, Single), а Index трогайте только в случае необходимости.

5.3 Как открыть и изучить шаблоны

Давайте посмотрим на шаблоны вживую.

  1. Откройте Редактор сайта: «Внешний вид → Редактор».
  2. В левой панели выберите «Шаблоны» (Templates).
  3. Вы увидите список всех доступных шаблонов. Рядом с каждым отображается превью и количество страниц, к которым он применяется.
  4. Нажмите на любой шаблон — например, «Page». Откроется его структура на холсте.
  5. Изучите блоки: вы увидите шапку, содержимое, подвал.
  6. Откройте навигатор блоков (иконка «Структура» в верхней панели) — посмотрите дерево шаблона.
  7. Кликните на любой блок — в правой панели появятся его настройки.
  8. Посмотрите на список ниже: WordPress показывает, к каким страницам применяется этот шаблон.
💡 Совет: Обязательно изучите все шаблоны вашей темы. Даже если вы не планируете их редактировать, вы должны знать, что где находится. Это поможет быстрее ориентироваться в дальнейшем.

5.4 Редактирование существующего шаблона

Редактирование шаблона похоже на редактирование обычной страницы, но есть нюансы.

Что можно менять в шаблоне

  • Добавлять блоки — например, вывести дату публикации под заголовком записи.
  • Удалять блоки — например, убрать блок комментариев из шаблона записи.
  • Менять порядок блоков — переместить метаданные записи выше или ниже.
  • Настраивать стили — цвета, шрифты, отступы для конкретного шаблона.
  • Изменять структуру — добавить колонки, контейнеры, вложенные секции.

Пример: добавляем блок «Хлебные крошки» в шаблон Page

  1. Откройте Редактор сайта → Шаблоны → Page.
  2. Найдите блок «Заголовок записи» (Post Title) — он отображает заголовок страницы.
  3. Наведите курсор перед этим блоком — появится синяя линия-индикатор.
  4. Нажмите на «+» — откроется библиотека блоков.
  5. Введите в поиске «Breadcrumbs» или «Хлебные крошки».
  6. Если блок найден — вставьте его. Если нет (в стандартном WordPress его нет) — используйте плагин для хлебных крошек или пропустите этот шаг.
  7. Настройте отступы для нового блока через правую панель.
  8. Нажмите «Сохранить».
  9. Проверьте любую страницу сайта — теперь над заголовком появились хлебные крошки.
✅ Готово! Ваше изменение применилось ко всем страницам, которые используют шаблон Page. Это главное отличие шаблонов от страниц: изменение шаблона влияет на все страницы, изменение страницы — только на неё.

5.5 Создание нового шаблона

Иногда стандартных шаблонов недостаточно. Например, вам нужна особая структура для лендинга услуг, отличная от обычной страницы. В этом случае создаётся собственный шаблон.

Пошаговая инструкция

  1. Откройте Редактор сайта → Шаблоны.
  2. Нажмите на «+» (Добавить новый шаблон) в верхней части списка.
  3. Выберите тип шаблона. Появится окно с вариантами:
    • Стандартный шаблон (Standard) — для страниц, записей, архивов и т. д.
    • Специфичный (Specific) — с привязкой к конкретной странице, категории, автору.
  4. Выберите «Страница» (Page) как базовый тип.
  5. Введите название шаблона — например, «Лендинг услуг».
  6. Нажмите «Создать». Откроется пустой шаблон с базовой структурой.
  7. Добавьте нужные блоки: контейнеры, заголовки, изображения, кнопки.
  8. Настройте стили и отступы через правую панель.
  9. Нажмите «Сохранить». Шаблон появится в списке.
💡 Важно понимать: Новый шаблон не применяется автоматически. Его нужно назначить конкретной странице или типу страниц. Как это сделать — читайте в следующем разделе.

5.6 Назначение шаблона странице

Когда шаблон создан, его нужно привязать к странице. Это делается в редакторе самой страницы.

Пошаговая инструкция

  1. Перейдите в «Страницы → Все страницы».
  2. Откройте нужную страницу для редактирования.
  3. В правой панели найдите раздел «Шаблон» (Template).
  4. В выпадающем списке выберите созданный вами шаблон — например, «Лендинг услуг».
  5. Нажмите «Обновить».
  6. Откройте страницу на сайте — она теперь использует новый шаблон.
💡 Практический приём: Создайте один шаблон-лендинг с полноценной структурой (Hero, преимущества, услуги, CTA). Затем создавайте страницы-лендинги и назначайте им этот шаблон. Каждая страница будет иметь свой уникальный контент, но одинаковую структуру. Это очень удобно для серийных проектов.

Назначение шаблона для целого типа страниц

Если вы создали шаблон и хотите применить его ко всем страницам определённого типа (например, ко всем записям категории «Новости»), это делается через специфичные шаблоны:

  1. Создайте новый шаблон в разделе «Шаблоны».
  2. При создании выберите «Специфичный» (Specific).
  3. Укажите, к чему привязать: конкретная страница, категория, автор и т. д.
  4. Выберите нужный объект из списка.
  5. Настройте структуру шаблона.
  6. Сохраните. WordPress автоматически применит этот шаблон ко всем страницам выбранного типа.

5.7 Практический пример: создаём шаблон для страницы «Услуги»

Давайте создадим кастомный шаблон для страницы услуг, который будет отличаться от обычной страницы.

  1. Откройте Редактор сайта → Шаблоны.
  2. Нажмите «+».
  3. Выберите тип «Страница».
  4. Назовите шаблон «Страница услуг».
  5. Нажмите «Создать».
  6. Удалите стандартные блоки (если они есть).
  7. Добавьте контейнер для Hero-секции:
    • Заголовок H1: «Наши услуги».
    • Подзаголовок: краткое описание.
    • Кнопку «Связаться с нами».
  8. Добавьте блок «Паттерн» с карточками услуг (если есть готовый) или создайте контейнер с тремя колонками вручную.
  9. В каждой колонке разместите: иконку, заголовок H3, текст, кнопку.
  10. Добавьте секцию с CTA — заголовок + кнопка.
  11. Настройте отступы и цвета через правую панель.
  12. Сохраните шаблон.
  13. Перейдите в «Страницы» и создайте новую страницу «Услуги».
  14. В правой панели в разделе «Шаблон» выберите «Страница услуг».
  15. Опубликуйте страницу.
  16. Проверьте результат: страница «Услуги» теперь использует ваш кастомный шаблон.
✅ Готово! Вы создали кастомный шаблон и применили его к конкретной странице. Этот шаблон можно использовать для любых других страниц — просто назначьте его в настройках.

5.8 Продвинутый приём: шаблон для лендинга без шапки и подвала

Часто лендинги делают без стандартной шапки и подвала, чтобы посетитель не отвлекался. В FSE это делается легко.

  1. Создайте новый шаблон в разделе «Шаблоны».
  2. Выберите тип «Страница».
  3. Назовите «Лендинг минимальный».
  4. Нажмите «Создать».
  5. Удалите блоки «Header» и «Footer» из шаблона (используйте навигатор блоков для точного выделения).
  6. Оставьте только блок «Post Content» — контент страницы.
  7. Оберните Post Content в контейнер и задайте ему нужный фон.
  8. Добавьте блок «Мини-шапка» (если нужно) — с логотипом и кнопкой, но без меню.
  9. Сохраните шаблон.
  10. Создайте страницу «Курс» и назначьте ей этот шаблон.
  11. Наполните страницу контентом через редактор страниц.
  12. Опубликуйте. Посетитель увидит чистый лендинг без отвлекающих элементов.
⚠️ Важно: На странице с таким шаблоном посетитель не сможет перейти в другие разделы сайта, если вы не добавите ссылки вручную. Убедитесь, что ключевые навигационные элементы (ссылка на главную, кнопка «Связаться») присутствуют в контенте.

5.9 Решение частых проблем с шаблонами

Проблема Причина Решение
Изменения в шаблоне не видны на сайте Кэш браузера или сайта Очистите кэш браузера (Ctrl+F5) и кэш-плагина
Шаблон не применяется к странице Не назначен в настройках страницы Откройте страницу → правая панель → «Шаблон» → выберите нужный
Созданный шаблон не отображается в списке Шаблон не сохранён Проверьте, нажали ли вы «Сохранить» в Редакторе сайта
Кастомный шаблон переопределяет всё Он назначен слишком широко Проверьте назначение — возможно, вы применили его ко всем страницам
Изменения в шаблоне Page затронули все страницы Так и должно быть — шаблон общий Если нужно изменить одну страницу — редактируйте её контент, а не шаблон
Хлебные крошки или другие блоки не отображаются Блок требует плагина или темы Установите соответствующий плагин или используйте другой блок
Не могу найти кнопку «Сохранить» Нет несохранённых изменений Внесите любое изменение — кнопка появится
Структура шаблона «сломалась» после правок Случайно удалён или перемещён важный блок Используйте «Отменить» (Ctrl+Z) или восстановите из резервной копии

5.10 Практическое задание

📝 Задание для самопроверки

Часть 1: Изучение существующих шаблонов
1. Откройте «Внешний вид → Редактор → Шаблоны».
2. Изучите шаблон «Page» — какие блоки в нём есть.
3. Изучите шаблон «Single» — чем он отличается от Page.
4. Изучите шаблон «404» — что показывает эта страница.
5. Запишите, какие шаблоны использует ваша тема.

Часть 2: Редактирование шаблона
6. Откройте шаблон «Page».
7. Добавьте блок «Разделитель» между заголовком и контентом.
8. Измените цвет фона контента на светло-серый.
9. Сохраните изменения.
10. Откройте любую страницу сайта — проверьте, что изменения применились.

Часть 3: Создание нового шаблона
11. Нажмите «+» в разделе «Шаблоны».
12. Выберите тип «Страница».
13. Назовите шаблон «Тестовый лендинг».
14. Удалите шапку и подвал (оставьте только Post Content).
15. Добавьте перед Post Content контейнер с заголовком H1 «Добро пожаловать».
16. Сохраните шаблон.

Часть 4: Применение шаблона
17. Создайте новую страницу «Тест-лендинг».
18. В правой панели выберите шаблон «Тестовый лендинг».
19. Опубликуйте страницу.
20. Откройте её на сайте — убедитесь, что шапка и подвал отсутствуют.
21. Вернитесь в редактор и назначьте странице стандартный шаблон «Page».
22. Проверьте, что шапка и подвал вернулись.

Часть 5: Финальная проверка
23. Убедитесь, что все изменения сохранены.
24. Проверьте сайт на компьютере и телефоне.
25. Если что-то не понравилось — вернитесь и исправьте.

5.11 Часто задаваемые вопросы

  • Чем шаблон отличается от страницы? Страница — это контент (текст, изображения). Шаблон — это структура, в которую этот контент вставляется. Один шаблон может использоваться для множества страниц.
  • Что будет, если удалить шаблон? Страницы, которые его использовали, переключатся на шаблон по умолчанию (обычно Index). Контент при этом не пострадает.
  • Можно ли восстановить удалённый шаблон? Если шаблон был из темы — да, при переустановке темы. Если вы создали его сами — только из резервной копии.
  • Как узнать, какой шаблон применяется к странице? Откройте страницу в редакторе — в правой панели в разделе «Шаблон» будет указан текущий.
  • Можно ли изменить шаблон для всех записей одной категории? Да, через специфичный шаблон с привязкой к категории.
  • Что такое «Blank» шаблон? Это пустой шаблон без шапки, подвала и контента. Используется как основа для полной кастомизации.
  • Сколько шаблонов можно создать? Неограниченно. Но для производительности рекомендуется не создавать шаблоны «на всякий случай» — только те, что реально используются.
