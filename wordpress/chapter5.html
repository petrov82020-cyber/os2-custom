Глава 5: Редактирование шаблонов (Templates) в Site Editor

✍️ Время чтения: ~18 минут | 🎯 Цель: научиться менять шапку, подвал и шаблоны страниц через визуальный редактор

Мы подошли к самому интересному этапу — изменению внешнего вида сайта. Раньше для этого требовался код или сложные настройки, но теперь всё делается через Site Editor. В этой главе мы разберём, что такое шаблоны (Templates) и части шаблонов (Template Parts), и научимся их редактировать.

💡 Что такое шаблон?
Шаблон — это «скелет» страницы. Он определяет, какие элементы где расположены: шапка сверху, подвал снизу, контент в центре. Один шаблон может использоваться для множества страниц. Например, шаблон «Главная страница» применяется только к главной, а шаблон «Страница» — ко всем обычным страницам.

5.1 Как открыть Site Editor

Напомню два способа входа:

  1. В левом меню админки: Внешний вид → Редактор (Appearance → Editor).
  2. Через верхнюю панель инструментов: кнопка Редактировать сайт (Edit site) при просмотре сайта.

Откроется полноэкранный редактор. Слева вы увидите вертикальное меню с двумя ключевыми разделами: Templates (Шаблоны) и Template Parts (Части шаблонов). Именно с ними мы будем работать.

5.2 Разбираемся с разделами Site Editor

Интерфейс Site Editor состоит из нескольких зон:

  • Левая боковая панель — список шаблонов и частей шаблона, а также настройки стилей.
  • Центральная область — живой предпросмотр сайта, где можно кликать по элементам и редактировать их.
  • Верхняя панель — кнопки сохранения, переключения устройств (компьютер/планшет/телефон), вызова списка блоков, настроек.
  • Правая панель — настройки выделенного блока (появляется при клике на элемент).

5.3 Какие шаблоны бывают

WordPress автоматически создаёт набор шаблонов в зависимости от темы. Вот самые важные:

🏠 Index / Главная страница Основной шаблон для отображения главной страницы сайта. Если не задано иное, используется для всего сайта.
📄 Page (Страница) Шаблон для обычных статических страниц: «О нас», «Услуги», «Контакты».
📝 Single Post (Запись) Шаблон для отображения отдельной записи блога.
📚 Archive (Архив) Шаблон для страниц архивов: список записей по дате, категории, автору.
🔍 Search (Поиск) Шаблон для страницы результатов поиска по сайту.
🚫 404 Шаблон для страницы «Не найдено».
👤 Author (Автор) Шаблон для страницы автора записей.
🗂️ Category (Категория) Шаблон для отображения записей определённой категории.

Щёлкните по любому шаблону в левой панели — откроется его предпросмотр. Вы увидите, что шаблон состоит из блоков: шапки, контента, подвала.

⚠️ Важно: Некоторые темы могут не поддерживать FSE, и тогда Site Editor будет недоступен. Для нашего курса используйте Twenty Twenty-Four или Twenty Twenty-Five — они полностью совместимы.

5.4 Редактирование шапки (Header)

Шапка — это верхняя часть сайта, которая обычно содержит логотип, название и меню. Она относится к частям шаблона (Template Parts), потому что используется на всех страницах.

Как отредактировать шапку

  1. В левой панели Site Editor нажмите Template Parts (Части шаблона).
  2. Найдите пункт Header (Шапка) и нажмите на него.
  3. Откроется шапка в режиме редактирования. Вы увидите блоки: «Название сайта», «Логотип», «Навигация».
  4. Кликните на любой блок, чтобы изменить его содержимое или настройки:
    • Название сайта — можно заменить на текст или сделать ссылкой на главную.
    • Логотип — вставьте изображение из медиабиблиотеки.
    • Навигация — добавьте пункты меню: «Главная», «О нас», «Услуги», «Контакты».
  5. Нажмите Сохранить в правом верхнем углу.
💡 Как добавить логотип: Внутри блока «Логотип» нажмите «Добавить изображение» (Add media), выберите файл из медиабиблиотеки или загрузите новый. Рекомендуемая высота логотипа — 40–60 пикселей.

Настройка меню навигации

Блок навигации — ключевой элемент шапки. С его помощью создаётся главное меню сайта:

  1. Кликните на блок «Навигация».
  2. Нажмите на кнопку + внутри блока, чтобы добавить новый пункт.
  3. Выберите тип ссылки:
    • Страница — ссылка на существующую страницу сайта.
    • Произвольная ссылка — любой URL.
    • Рубрика — если ведёте блог.
  4. Повторите для всех пунктов меню.
  5. Порядок пунктов можно менять перетаскиванием.

5.5 Редактирование подвала (Footer)

Подвал — нижняя часть сайта, где обычно размещают копирайт, ссылки на соцсети и контакты. Редактируется аналогично шапке.

  1. В левой панели выберите Template Parts → Footer.
  2. Откроется подвал. По умолчанию это абзац с текстом «© Название сайта».
  3. Кликните на текст и измените его, например: «© 2026 Мой первый сайт. Все права защищены.».
  4. Можно добавить блок «Колонки», чтобы разместить в подвале несколько секций: контакты, ссылки, соцсети.
  5. Нажмите Сохранить.
💡 Идея для подвала: Создайте три колонки. В левой — копирайт, в центральной — ссылки на страницы «О нас» и «Контакты», в правой — иконки соцсетей или email. Так подвал будет выглядеть профессионально.

5.6 Редактирование шаблона страницы

Теперь разберёмся, как изменить шаблон обычной страницы. Это позволит настроить макет, который будет применяться ко всем страницам типа «Page».

  1. В левой панели нажмите Templates (Шаблоны).
  2. Найдите шаблон Page (Страница) и кликните по нему.
  3. Откроется предпросмотр шаблона. Вы увидите:
    • Шапку (Header) — часть шаблона, которую мы уже настроили.
    • Блок Post Content (Содержимое страницы) — сюда подставляется текст конкретной страницы.
    • Подвал (Footer).
  4. Можно добавить вокруг контента дополнительные блоки: например, «Заголовок страницы» или «Хлебные крошки».
  5. Нажмите Сохранить.
⚠️ Важно: Блок Post Content нельзя удалять — он отвечает за вывод содержимого каждой конкретной страницы. Если его убрать, страницы станут пустыми.

5.7 Создание собственного шаблона

Иногда стандартных шаблонов не хватает. Например, вы хотите создать страницу «Портфолио» с уникальным дизайном. Site Editor позволяет добавить новый шаблон:

  1. В разделе Templates нажмите кнопку + (Добавить шаблон).
  2. Выберите тип: Страница (Page) или Своя конфигурация (Custom template).
  3. Введите название, например «Портфолио».
  4. Настройте макет: добавьте блоки, измените расположение элементов.
  5. Сохраните шаблон.
  6. Теперь при редактировании любой страницы в правой панели можно выбрать этот шаблон в разделе Шаблон (Template).

5.8 Настройка главной страницы

По умолчанию главная страница WordPress показывает ленту записей. Но для сайта-визитки удобнее назначить статическую страницу.

  1. Создайте страницу с названием «Главная» и наполните её блоками.
  2. Перейдите в Настройки → Чтение.
  3. В разделе «На главной странице отображать» выберите Статическую страницу.
  4. В выпадающем списке «Домашняя страница» выберите «Главная».
  5. Нажмите Сохранить изменения.
💡 Что это даёт: Теперь главная страница будет показывать именно тот контент, который вы создали, а не список записей. Это правильный подход для сайта-визитки, портфолио или лендинга.

5.9 Частые вопросы

  • Я изменил шапку, но на сайте всё по-старому. Убедитесь, что нажали Сохранить в Site Editor. Также очистите кэш браузера (Ctrl+F5).
  • Можно ли отменить изменения? Да, при редактировании шаблона нажмите на три точки в верхней панели и выберите Отменить (Undo).
  • Что делать, если я сломал шаблон? В левой панели можно сбросить шаблон к настройкам темы по умолчанию.
  • Изменения в шаблоне влияют на все страницы? Да, если это шаблон Page. Если хотите изменить одну страницу — редактируйте её контент в разделе «Страницы».
📝 Задание для самопроверки
1. Откройте Site Editor через меню «Внешний вид → Редактор».
2. Отредактируйте шапку: добавьте название сайта и логотип.
3. Создайте меню навигации с пунктами: Главная, О нас, Контакты.
4. Отредактируйте подвал: добавьте копирайт и email.
5. Откройте шаблон Page и убедитесь, что блок «Post Content» на месте.
6. Создайте новую страницу «Главная» и назначьте её домашней через Настройки → Чтение.
7. Проверьте сайт — шапка и подвал должны обновиться на всех страницах.
