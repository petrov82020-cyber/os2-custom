Глава 7: Публикация сайта и подключение бесплатного SSL

✍️ Время чтения: ~18 минут | 🎯 Цель: настроить постоянные ссылки, подключить HTTPS и убедиться, что сайт работает корректно

Мы проделали огромную работу: создали аккаунт на хостинге, установили WordPress, научились работать с блоками, шаблонами и стилями. Теперь пришло время убедиться, что ваш сайт работает правильно и доступен всем посетителям. В этой главе мы настроим постоянные ссылки, подключим бесплатный SSL-сертификат и проверим сайт на ошибки.

💡 Что такое SSL и зачем он нужен?
SSL (Secure Sockets Layer) — это технология шифрования, которая защищает данные между браузером посетителя и вашим сайтом. Если у сайта нет SSL, адрес начинается с http://, а браузеры помечают его как «Не защищено». С SSL адрес начинается с https://, и рядом появляется замок. Это важно для доверия посетителей и для SEO — Google отдаёт предпочтение защищённым сайтам.

7.1 Настройка постоянных ссылок (Permalinks)

По умолчанию WordPress использует «некрасивые» адреса страниц вида https://ваш_домен/?p=123. Их сложно запомнить, и они плохо влияют на SEO. Настроим «человекопонятные» URL.

  1. Войдите в админ-панель WordPress.
  2. Перейдите в Настройки → Постоянные ссылки.
  3. Выберите вариант «Название записи» (Post name).
  4. Нажмите Сохранить изменения.

Теперь адреса страниц будут выглядеть так: https://ваш_домен/o-nas/ вместо https://ваш_домен/?page_id=2.

⚠️ Если после смены постоянных ссылок страницы перестали открываться (ошибка 404): WordPress автоматически создаёт файл .htaccess с правилами перенаправления. На некоторых хостингах этот файл может не создаться. Тогда нужно создать его вручную.

Создание .htaccess вручную (если нужно)

  1. В панели управления хостингом (cPanel) откройте Файловый менеджер.
  2. Перейдите в папку htdocs (это корень вашего сайта).
  3. Создайте новый файл с именем .htaccess (обязательно с точкой в начале).
  4. Вставьте в него следующий код:
# BEGIN WordPress
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteBase /
RewriteRule ^index\.php$ - [L]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule . /index.php [L]
</IfModule>
# END WordPress

Это стандартный набор правил для WordPress, который заставляет сервер перенаправлять все запросы на index.php, если файл не найден напрямую. Без него «красивые» ссылки не будут работать.

💡 Совет: Если вы не уверены, что .htaccess создался автоматически, проверьте его наличие через файловый менеджер. Если файла нет — создайте вручную с кодом выше.

7.2 Бесплатный SSL на InfinityFree — хорошие новости

Отличная новость: если вы используете бесплатный поддомен InfinityFree (например, ваше_имя.epizy.com или ваше_имя.rf.gd), то SSL уже включён автоматически. Все бесплатные поддомены защищены системным сертификатом, и вам не нужно ничего запрашивать вручную.[reference:0]

✅ Что это значит для вас: Ваш сайт уже доступен по адресу https://ваше_имя.epizy.com. Не нужно нажимать никаких кнопок «Получить SSL» — сертификат уже работает.

Если же вы решите подключить собственный домен (например, купленный отдельно), то для него потребуется запросить бесплатный SSL-сертификат через панель InfinityFree. Процесс выглядит так:

  1. В личном кабинете InfinityFree перейдите в раздел Free SSL Certificates.
  2. Нажмите New SSL Certificate.
  3. Введите ваш домен и выберите провайдера ZeroSSL (или оставьте «Recommended»).[reference:1]
  4. Нажмите Create Order, затем Setup CNAME Records — система автоматически добавит нужные записи DNS.
  5. Подождите 5–10 минут, пока домен подтвердится. Кнопка Request Certificate станет активной — нажмите её.
  6. После выпуска сертификата нажмите Install SSL Certificate Automatically.[reference:2]
⚠️ Важно: Бесплатные SSL-сертификаты на InfinityFree не продлеваются автоматически. При использовании собственного домена вам придётся раз в 3 месяца запрашивать новый сертификат. Для бесплатного поддомена это не требуется — там сертификат системный.

7.3 Принудительное перенаправление на HTTPS

Даже если SSL установлен, сайт может по-прежнему открываться по http://. Нужно заставить WordPress использовать https:// всегда. Есть два способа.

Способ 1: Через настройки WordPress (рекомендуется)

  1. Перейдите в Настройки → Общие.
  2. В полях Адрес WordPress (URL) и Адрес сайта (URL) замените http:// на https://.
  3. Нажмите Сохранить изменения.

WordPress автоматически будет использовать HTTPS для всех ссылок. Этот способ работает без правки файлов.[reference:3]

Способ 2: Через .htaccess (для продвинутых)

Если по какой-то причине первый способ не сработал, можно добавить правило в .htaccess:

RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

Этот код перенаправляет всех посетителей с http:// на https:// с кодом 301 (постоянное перенаправление).[reference:4]

💡 Какой способ выбрать? Для WordPress всегда используйте Способ 1 — он проще и безопаснее. Правка .htaccess может привести к конфликтам, если у вас уже есть другие правила.

7.4 Проверка работы сайта

После настройки SSL и постоянных ссылок давайте убедимся, что всё работает правильно.

Чек-лист проверки

  1. Откройте сайт по адресу https://ваш_домен. Рядом с адресом должен быть замок. Если замка нет — проверьте, правильно ли установлен SSL.
  2. Откройте любую страницу (например, «О нас»). Она должна открываться по красивому адресу https://ваш_домен/o-nas/.
  3. Проверьте навигацию. Все пункты меню должны работать.
  4. Откройте сайт на телефоне. Убедитесь, что вёрстка не «разъезжается» и текст читается.
  5. Проверьте админ-панель. Войдите в https://ваш_домен/wp-admin — всё должно работать так же, как и раньше.

Инструменты для проверки SSL

  • SSL Labs (ssllabs.com/ssltest) — глубокий анализ сертификата.
  • Why No Padlock? (whynopadlock.com) — покажет, какие элементы на странице загружаются по HTTP и мешают замку.
💡 Совет: Если замок не появляется, откройте сайт в режиме инкогнито. Иногда браузер кэширует старую версию страницы без HTTPS.

7.5 Что значит «Website Published» в панели InfinityFree

В личном кабинете InfinityFree рядом с вашим аккаунтом есть поле Website Published. Если вы устанавливали WordPress через Softaculous (а не через встроенный конструктор Site.pro), там может стоять красный крест. Не пугайтесь!

Это поле относится только к конструктору сайтов Site.pro. Оно не имеет отношения к вашему WordPress-сайту.[reference:5] Если вы видите красный крест, но ваш сайт открывается и работает — всё в порядке. Игнорируйте этот индикатор.

7.6 Базовые плагины для нового сайта

Хотя наш курс посвящён встроенным возможностям WordPress, стоит упомянуть несколько бесплатных плагинов, которые пригодятся почти всем.

  • Really Simple SSL — автоматически настраивает HTTPS и исправляет смешанный контент. Полезен, если замок не появляется.
  • WordPress SEO (Yoast SEO) — помогает оптимизировать страницы для поисковых систем.
  • WP Super Cache — ускоряет загрузку сайта за счёт кэширования.
  • Contact Form 7 — создаёт формы обратной связи.
  • UpdraftPlus — резервное копирование сайта.

Устанавливать плагины можно через Плагины → Добавить новый. Но на бесплатном хостинге не стоит устанавливать слишком много — это замедлит сайт.

⚠️ Осторожно: Некоторые плагины могут конфликтовать с бесплатным хостингом или требовать больше ресурсов, чем доступно. Устанавливайте только те, которые действительно нужны.

7.7 Типичные проблемы и их решения

  • Страницы не открываются (404). Проверьте настройки постоянных ссылок и наличие файла .htaccess в папке htdocs.
  • Замка SSL нет. Откройте сайт в инкогнито. Если не помогло — используйте Really Simple SSL или проверьте, что URL в настройках WordPress начинается с https://.
  • Сайт открывается по http://, а не https://. Замените URL в настройках WordPress (Настройки → Общие).
  • После смены домена сайт не работает. Если вы меняли домен, нужно обновить URL в базе данных. Это можно сделать через плагин или вручную через phpMyAdmin.
  • Админка недоступна. Попробуйте открыть https://ваш_домен/wp-admin напрямую. Если не работает — очистите кэш браузера.
📝 Задание для самопроверки
1. Перейдите в Настройки → Постоянные ссылки и выберите «Название записи».
2. Проверьте, что в папке htdocs есть файл .htaccess с правилами WordPress.
3. Убедитесь, что ваш сайт открывается по https:// (замок в браузере).
4. В Настройки → Общие проверьте, что оба URL начинаются с https://.
5. Откройте сайт на телефоне и проверьте навигацию.
6. Войдите в админ-панель /wp-admin и убедитесь, что всё работает.
7. Если замка нет — установите плагин Really Simple SSL и активируйте его.
